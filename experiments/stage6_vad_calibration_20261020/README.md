# 6단계 무발화 판정·신뢰도 기준 보정 (2026-10-20)

녹화 분석의 "[발화 없음]"과 "[인식 불가]" 판정에 쓰는 기준값을 정한 기록이다. 수치는 [calibration.json](calibration.json)에 있다.

## 정한 값

| 값 | 위치 | 내용 |
|---|---|---|
| `VAD_*` | `scripts/olkavs_transcribe.py` | 입 벌림 비율의 0.4초 범위가 0.005 이상이면 말하는 프레임. 0.8초 미만 멈춤은 메우고 0.3초 미만 움직임은 버린다. 녹화는 발화 앞 0.4초, 뒤 0.5초를 남기고 자른다. 활성 0.4초 미만이면 발화 없음. |
| `OLKAVS_MIN_CONFIDENCE` | `backend/config.py` | 0.75. 이보다 낮으면 "[인식 불가]"로 바꾸고 모델 문장은 `candidate`로 남긴다. |

## 근거

AI Hub 학습 자료 6명·6녹화(각 약 5분, 1080p, 문장 라벨 269개)를 실제 입술 추적기로 처리했다.

| 확인 | 결과 |
|---|---|
| 문장 안 프레임 재현율 | 0.975 |
| 말하는 6초 창 3,578개 중 "발화 없음" | 0 |
| 문장±2.5초 녹화 모의 269개 중 "발화 없음" | 0 |
| 문장 사이 3초 무발화 모의 37개 중 "발화 없음" | 26 |
| 업로드 경로 문자 오류율 C297 | 16.51% (5단계와 같음) |
| 신뢰도 0.75 미만으로 숨는 좋은 결과(오류율 30% 이하) | 0 / 144 |
| 신뢰도 0.75 미만으로 숨는 무발화 강제 인식 | 16 / 27 |

## 한계

- 소리 내어 말하는 고해상도 AI Hub 자료만 썼다. 웹캠, 소리 없이 말하기, 처음 보는 사람은 검증하지 않았다.
- 말하지 않을 때도 입을 움직이는 사람은 무발화 구간이 말하는 것으로 잡힐 수 있다. 말을 지우는 것보다 남기는 쪽을 택했다.
- 정지 화면을 강제로 인식하면 신뢰도가 0.92로 높게 나온다. 이런 입력은 신뢰도가 아니라 입 움직임 판정이 거른다.

## 팀 촬영 자료로 다시 맞추기

3단계 파일럿 녹화가 모이면 같은 도구로 다시 잰다. 라벨은 발화 구간 `[[시작초, 끝초], ...]` 목록 JSON이나 AI Hub 라벨 JSON을 쓴다.

```bash
.venv-olkavs-roi/Scripts/python.exe scripts/calibrate_vad.py dump --help
```

```bash
.venv-olkavs-roi/Scripts/python.exe scripts/calibrate_vad.py evaluate --help
```

말하지 않는 영상(무발화 10개)이 "[발화 없음]"이 되는지, 소리 없이 말한 영상이 잘리지 않는지를 먼저 본다.
