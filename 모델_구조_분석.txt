================================================================================
립리딩(Lip Reading) AI 모델 분석
================================================================================

이 프로젝트는 말소리 없이 입술 움직임만으로 한국어 문장을 인식하는(무성
음성인식) 딥러닝 모델이다. 영상 속 입 모양의 시간적 변화를 읽어 한글 텍스트로
복원한다.

--------------------------------------------------------------------------------
한 줄 요약
--------------------------------------------------------------------------------
LipNet 계열 아키텍처 — 3D-CNN(시공간 특징) → BiLSTM(시퀀스 모델링) → CTC(정렬
없는 분류) 구조로, 한글을 자모(자음·모음) 단위로 인식한 뒤 완성형 음절로
재조합한다.


================================================================================
1. 모델 아키텍처 (backend/models/baseline.py)
================================================================================
LipNetBaseline 클래스가 핵심이며, 3단계 신경망으로 구성된다.

  입력 (B, 3, 75, 96, 96)   ← 배치, RGB채널, 시간(프레임), 세로, 가로
     │
     ├─ ① 3D-CNN 블록 ×3 (시공간 특징 추출)
     │     Conv3d(3→32)  + BN + ReLU + MaxPool(1,2,2) → (B,32,T,48,48)
     │     Conv3d(32→64) + BN + ReLU + MaxPool(1,2,2) → (B,64,T,24,24)
     │     Conv3d(64→96) + BN + ReLU                  → (B,96,T,24,24)
     │     ※ MaxPool 커널이 (1,2,2) → 공간만 절반씩 줄이고 시간축 T는 절대 보존
     │
     ├─ ② temporal flatten → (B, T, 96×24×24=55296)
     │
     ├─ ③ BiLSTM (양방향 LSTM, hidden=256, 2층) → (B, T, 512)
     │     ※ 양방향이라 앞뒤 문맥을 모두 봄 (입술은 앞뒤 프레임 맥락이 중요)
     │
     ├─ ④ Linear(512 → 41) + LogSoftmax → (B, T, 41)
     │
     └─ ⑤ permute → (T, B, 41)   ← CTC Loss가 요구하는 형태

설계의 핵심 포인트:
  - 3D-CNN: 일반 CNN과 달리 시간축까지 함께 컨볼루션해서, "입술이 어떻게
    움직이는가"라는 동적 패턴을 포착한다.
  - 시간축 보존 (MaxPool3d(1,2,2)): 풀링을 공간(H,W)에만 적용하고 시간(T)은
    줄이지 않는다. 출력 시퀀스 길이 T'=T를 유지해야 CTC가 라벨을 정렬할 수
    있기 때문이다 (CLAUDE.md의 "temporal 풀링 금지" 규칙).
  - 41개 출력 클래스 (models/__init__.py): 자음 19 + 모음 21 + blank 1 = 41.
    blank는 CTC 표준에 따라 인덱스 0으로 고정.


================================================================================
2. CTC — 정렬 라벨 없이 학습하는 핵심 원리
================================================================================
이 모델의 가장 중요한 원리는 CTC(Connectionist Temporal Classification)이다.

문제: 영상은 75프레임인데 정답은 "안녕하세요"(자모 10개)다. "어느 프레임이
어느 자모에 해당하는지" 정렬 정보가 없다.

CTC의 해법: 모델이 매 프레임마다 자모 또는 blank(공백)를 출력하게 하고, 학습
시 가능한 모든 정렬을 확률적으로 합산한다. 디코딩 시엔 연속 중복 제거 + blank
제거로 최종 시퀀스를 얻는다.
  - 예: ㅇㅇblankㅏㅏㄴ → ㅇ ㅏ ㄴ

prepare_data.py:ctc_min_input_len에서 이 제약을 엄밀히 검사한다 — CTC는 인접한
동일 자모 사이에 반드시 blank가 필요하므로,
  필요한 최소 프레임 수 = 라벨 길이 + 인접 중복 자모 쌍의 수
이보다 짧은 클립은 학습에서 제외해 "gradient가 조용히 0이 되는" 표본을 걸러낸다.

학습(train.py)은 nn.CTCLoss(blank=0, zero_infinity=True)를 사용한다.


================================================================================
3. 디코딩 — 자모 → 한글 음절 복원 (backend/models/decoder.py)
================================================================================
모델 출력(프레임별 41클래스 로그확률)을 실제 한글로 바꾸는 2단계:

  1. Prefix Beam Search (ctc_beam_search_decode): 단순히 매 프레임 최고 확률을
     고르는 대신(greedy), 여러 후보 경로(beam_width=10)를 유지하며 확률 총합이
     높은 자모 시퀀스를 탐색.

  2. 자모 → 음절 결합 (compose_jamos, python-jamo의 j2h): 초성(자음) +
     중성(모음) [+ 종성(자음)] 규칙으로 그리디하게 조합. 예: ㅇ ㅏ ㄴ ㄴ ㅕ ㅇ
     → "안녕". 종성 불가 쌍자음(ㄸ/ㅃ/ㅉ)은 받침으로 쓰지 않는 등 한글 조합
     규칙을 반영.

신뢰도 계산 (get_confidence):
  - raw_score  = 프레임별 최대 log-prob의 합 (CTC 원본 점수, 음수)
  - confidence = exp(raw_score / T) = 프레임별 최대 확률의 기하평균 → 0~1
    정규화값


================================================================================
4. 전처리 파이프라인 — 영상을 모델 입력으로
================================================================================
추론 시 (preprocessing/pipeline.py):

  영상 → ① 길이검증(180초 제한) → ② 25fps 리샘플링(타임스탬프 기반)
       → ③ 3초(75프레임) 세그먼트 분할 → ④ 입술 ROI 추출 → ⑤ 정규화 → 텐서

입술 ROI 추출 (roi_extractor.py)이 두 경로로 나뉜다:
  - MediaPipe 경로: Face Mesh로 얼굴 랜드마크 검출 → 외측 입술 20개 좌표로
    바운딩박스 → 상하좌우 20% margin → 96×96 리사이즈. 여러 명이면 가장 큰
    얼굴 1인만 추적, 연속 12프레임 미검출 시 세그먼트 폐기, 일시적 미검출은
    forward/back-fill (zero-padding 금지).
  - bbox 경로 (crop_roi_from_box): AI Hub 라벨에 든 프레임별 입술 좌표를 직접
    사용 → MediaPipe보다 ~2.4배 빠르고 미검출 없음.

정규화: (픽셀/255 - ImageNet평균)/ImageNet표준편차 후 (T,H,W,C)→(C,T,H,W)
permute해서 3D-CNN 입력 형태로 변환.


================================================================================
5. 학습 데이터 파이프라인 (scripts/prepare_data.py, train.py)
================================================================================
  - 데이터: AI Hub 립리딩 데이터셋. 원본은 30fps·1920×1080·5분(다문장). 라벨
    JSON의 Sentence_info[].start_time/end_time으로 문장 단위 클립을 잘라냄
    (영상당 51문장, 평균 5초).
  - 좌표 회전 정합 (_detect_rotation): 영상은 세로 촬영인데 가로로 저장돼 라벨
    좌표계가 90° 어긋남 → 프레임을 반시계 90° 회전해 정합 (자동 감지).
  - 라벨 인코딩 (encode_text): 한글 → h2j(자모분해) → j2hcj(호환자모) → 인덱스.
    한글 아닌 문자는 제외.
  - 가변 길이 학습: 문장마다 길이가 다르므로(42~294프레임) SEQ_LEN=75를 고정하지
    않고 런타임 T를 그대로 사용. LengthBucketBatchSampler로 비슷한 길이끼리
    배치해 last-frame 패딩 낭비 최소화, gradient clipping으로 CTC 학습 안정화,
    val CER로 best 체크포인트 저장.


================================================================================
6. 서빙 구조 (backend/api/infer.py)
================================================================================
FastAPI 기반 비동기 추론:
  - POST /api/infer → 즉시 {job_id, status:'processing'} 반환 (결과 즉시반환
    금지)
  - 백그라운드에서 전처리 → 세그먼트별 추론 → 진행률 갱신 → 완료 → 임시파일
    즉시 삭제(개인정보 보호)
  - GET /api/result/{session_id} → 폴링으로 결과 조회
  - 가중치가 없으면 [모델 미학습] 더미 텍스트 폴백


================================================================================
종합
================================================================================
  구성요소     | 기술                  | 역할
  -------------+-----------------------+----------------------------------------
  특징 추출    | 3D-CNN ×3             | 입술의 시공간 움직임 패턴 포착
  시퀀스 모델  | BiLSTM 2층            | 앞뒤 프레임 문맥으로 시간 의존성 학습
  손실/정렬    | CTC                   | 프레임-자모 정렬 정보 없이 학습
  출력 단위    | 한글 자모 41클래스    | 자음19+모음21+blank
  디코딩       | Beam Search + jamo    | 자모열 → 완성형 한글 음절

본질적으로 LipNet(2016) 아키텍처를 한국어 자모 인식에 맞게 변형한 모델이다.
영어 알파벳 대신 한글 자모를 CTC 클래스로 두고, 디코딩 단계에서 한글 조합
규칙으로 음절을 복원하는 것이 한국어 특화 포인트다.
