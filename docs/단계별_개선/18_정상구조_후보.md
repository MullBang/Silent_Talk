# 18단계: MP4 구조 검사 예비 통과 후보와 재확보 목록

정면 A 영상 180개를 검사한 결과, 구조 예비 통과는 17개이고 재확보 확인 대상은 163개입니다. 161개는 MP4 박스에 선언된 끝 위치가 실제 파일 크기를 넘었고, 나머지 2개는 실제 0바이트였습니다. 이 결과로 손상이나 누락이 발생한 시점을 단정할 수는 없습니다.

**17개는 재생 가능한 영상으로 확정된 파일이 아닙니다.** 최상위 박스의 경계와 `ftyp`·`mdat`·`moov` 존재를 확인한 단계이며, 영상 디코딩, 시간·프레임과 라벨의 정렬, 입술 ROI 검수는 아직 수행하지 않았습니다.

## 기존 입력 검수 계획에 미치는 영향

고정된 입력 검수 계획은 새 화자 15명 × 녹화 2개 × 문장 4개 = 120클립입니다. 선정 영상 30개 중 28개가 구조 검사에 실패하고 2개만 예비 통과했습니다. 예비 통과 영상에 연결된 8클립도 준비가 완료된 클립은 아닙니다. 실제 준비는 첫 영상에서 중단되어 완료 클립이 0개입니다.

보류 화자는 TS2의 C040, TS20의 C059, TS200의 C769입니다. 세 화자의 선정 영상 6개와 그에 연결된 24클립은 모두 실패 영상에 속합니다. 예비 통과한 다른 녹화로 고정된 선정 ID나 화자 역할을 자동 교체하지 않습니다.

## 0바이트 파일과 재확보 목록

[18_재확보_필요파일.txt](18_재확보_필요파일.txt)는 재확보 확인 대상 163개를 행 단위로 적은 UTF-8 BOM 탭 구분 텍스트입니다. `selected_pilot=true`인 28개가 기존 입력 검수 계획을 다시 진행하기 위해 우선 확보할 대상입니다. `source_path`와 `source_label_path`는 기존 원천 경로이며, 해당 원본이나 라벨은 이 보고 작업에서 수정하지 않았습니다.

아래 두 파일은 G: 경로에서 파일 크기와 수정 시각만 별도로 조회했으며 둘 다 존재하지만 0바이트였습니다. 영상 내용은 읽지 않았습니다.

- `lip_J_1_F_02_C075_A_011.mp4`: 0바이트, 원래 pilot 미포함, 원본 크기 추정 불가.
- `lip_J_6_M_03_C646_A_002.mp4`: 0바이트, 원래 pilot 미포함, 원본 크기 추정 불가.

`minimum_expected_bytes`는 헤더에 선언된 박스 끝까지 필요하다고 계산한 최소 파일 크기이며, `minimum_missing_bytes`는 그 크기에서 현재 파일 크기를 뺀 값입니다. 두 값은 **헤더의 크기 선언이 맞다는 조건**에서만 의미가 있습니다. 0바이트 파일의 값은 빈칸이며 0을 뜻하지 않습니다. `moov` 등의 후속 내용까지 포함한 완전한 원본 크기나 실제 재다운로드 용량은 이 값만으로 확정할 수 없습니다.

- 선언 범위 초과 161개: 선언 기준 최소 크기 합계 47,807,464,612바이트(44.524 GiB), 현재 크기와의 차이 합계 38,728,893,604바이트(36.069 GiB).
- 선정 영상 중 선언 범위 초과 28개: 선언 기준 최소 크기 합계 8,366,673,178바이트(7.792 GiB), 현재 크기와의 차이 합계 7,149,276,442바이트(6.658 GiB).

GiB는 1,073,741,824바이트입니다. 이 합계는 복구 후 실제 사용 공간이나 다운로드 예산을 확정하는 수치가 아닙니다.

## 근거와 해석 범위

첫 실패 영상 `lip_J_1_F_02_C040_A_001.mp4`는 현재 18,874,368바이트인데 헤더의 `mdat` 끝 위치는 348,888,707바이트입니다. 이 선언대로라면 최소 330,014,339바이트가 부족합니다. [preparation_failure.json](../../results/step18-intake/run01/preparation_failure.json)에 기록된 원천 파일과 로컬 사본의 SHA-256 일치는 복사 시점의 바이트 일치를 뒷받침하며, 원천 파일의 완전성을 보증하지 않습니다. 이 보고 작업에서 영상 전체 해시를 다시 계산하지는 않았습니다.

기존 선정 목록, 화자 역할, 모델, 학습 및 평가 자료는 변경하지 않았습니다. 구조 통과 후보는 별도 디코딩·시간 정렬·ROI 검수를 통과한 뒤에야 준비 가능한 자료로 판정할 수 있습니다. 원래 선정 파일을 확보하지 못해 다른 파일로 새 입력 검수를 구성할 경우, 기존 계획과 별도로 선정 근거와 분할 계약을 기록해야 합니다.
