01. 프로젝트 개요
1.1 추진 배경 및 필요성
음성 인식 기술은 조용한 환경에서는 높은 성능을 보이지만, 소음이 심한 산업 현장·재난 구조 환경·병원이나 도서관처럼 소리를 내기 어려운 공간, 또는 군사·보안 환경에서는 활용이 극도로 제한된다. 또한 발성은 어렵지만 입모양 움직임이 가능한 사용자, 그리고 무음 대화가 필요한 상황에서는 음성 외의 입력 방식이 필수적으로 요구된다.
립리딩은 입술 움직임과 얼굴 하관의 시각 정보를 이용해 발화 내용을 추정하는 기술이다. 본 프로젝트는 AI Hub의 한국어 립리딩 데이터셋을 활용하여 딥러닝 모델을 학습하고, 최종적으로 웹캠을 통해 실시간으로 텍스트를 추출하는 시연 가능한 웹 서비스를 구현하는 것을 목표로 한다.

※ 립리딩은 같은 입모양으로 여러 음소가 표현될 수 있어 완전한 자유 발화 인식의 난도가 매우 높다.
따라서 학기 내 완성도 확보를 위해 대면 안내·키오스크 명령어 등 실생활에서 자주 쓰이는
핵심 어휘 100종 및 지정 문장 50개 내외의 제한된 도메인을 1차 MVP 목표로 설정한다.

Python MediaPipe와 MediaPipe JS의 크롭 방식이 다르면 모델 성능이 저하될 수 있으므로, 추론 파이프라인도 동일 기준으로 구현한다.

03. 시스템 아키텍처
3.1 전체 처리 흐름
단계
처리 내용
① 입력 (Client)
HTML5 웹캠 API로 실시간 영상 스트림 활성화 / 또는 영상 파일 업로드
② 에지 전처리 + V-VAD (Client)
브라우저단 MediaPipe JS API로 얼굴 감지 및 입술 ROI 크롭.
V-VAD: 상하 입술 안쪽 랜드마크 간의 유클리드 거리(Euclidean Distance) 변화율과 움직임 분산(Variance)을 실시간 계산하여 임계값(Threshold)을 초과할 때를 발화 구간으로 정의, 실제 발화 프레임만 동적으로 크롭
③ 네트워크 전송 (WebSocket)
크롭된 입술 프레임 데이터를 직렬화 오버헤드 없는 바이너리 배열(ArrayBuffer) 형태로 변환하여 WebSocket 프로토콜로 최소 지연 스트리밍
④ 모델 추론 (Server)
3D-CNN + LSTM 기반 베이스라인, 또는 3D-ResNet 기반 개선 모델로 입술 시공간 특징 추출 및 문장 예측 (CTC 기반)
⑤ 디코딩 (Server)
Beam Search 디코딩 + 선택적 n-gram 언어 모델 후처리로 자모음 단위 텍스트 생성
⑥ 출력 (Client)
예측 텍스트를 WebSocket으로 클라이언트에 재전송, 웹 화면에 구간별 자막(2~3초 단위) 표출

3.2 실시간(Real-time) 기준 정의
립리딩 모델은 한 글자씩 즉시 인식하기보다 일정 구간의 영상 시퀀스를 보고 문장을 예측하는 방식이 일반적이다.
따라서 본 프로젝트에서 '실시간'은 완전 즉시 인식이 아닌 짧은 구간 단위 자막 표시로 정의한다.

항목
기준
입력 단위
2~3초 단위 영상 시퀀스 (V-VAD로 발화 구간 자동 감지)
출력 방식
구간 종료 후 자막 텍스트를 화면에 표시하는 구간별 스트리밍 자막
허용 지연
사용자가 발화를 마친 후 1초 이내 결과 표시 (도전 목표: 400ms 이하)
발화 구간 감지
V-VAD: 입술 유클리드 거리 변화율이 설정 임계값 초과 구간만 추론

09. 기대 효과 및 확장 가능성
9.1 직접 기대 효과
배리어프리(Barrier-Free) 서비스: 청각장애인·발성은 어렵지만 입모양 움직임이 가능한 사용자의 커뮤니케이션 보조 도구 제공
특수 환경 지원: 소음 극심한 산업 현장·재난 구조 환경·병원·도서관·군사·보안 환경 등에서 시각 기반 대체 입력 수단
무음 발화 입력: 소리를 내지 않고 텍스트를 입력하는 새로운 인터페이스 가능성 확인
End-to-End AI 파이프라인 경험: 컴퓨터비전·시계열 모델링·NLP 후처리·웹 서비스를 결합한 실전형 졸업과제

9.2 향후 확장 가능성
멀티모달 확장: 음성(Audio STT)과 입술 영상을 융합한 AVSR(Audio-Visual Speech Recognition)로 고도화
화자 적응: 개인별 fine-tuning 기능 추가로 인식률 향상
모바일 앱: TensorFlow Lite / Core ML 변환을 통한 iOS/Android 포팅
다국어 지원: 한국어 외 영어·중국어 립리딩 모델로 확장
