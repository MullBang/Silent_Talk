# 공식 모델 전환 7단계 — 지정 문장 보조 모드 결과

> 작성일: 2026-10-31 · 상위 계획: [공식모델_전환_실행계획_2026-10-20.md](공식모델_전환_실행계획_2026-10-20.md)
> 측정 자료: 파일럿 참가자 P01 한 명의 웹캠 100클립(1280×720, 소리 내어 40·소리 없이 40·자유 문장 10·말하지 않기 10). 조정용 자료이며 최종 평가가 아니다.

## 만든 것

녹화 경로(`POST /api/record`)에서 녹화 한 건 전체가 모델 창 하나일 때, 인식 워커가 자유 인식과 같은 프레임별 CTC 로그확률로 후보 문장마다 강제 정렬 점수(토큰당 평균)를 계산한다. 1등 문장과 1·2등 점수 차이(`margin`)를 결과의 `phrase`로 돌려준다.

- 후보 목록은 촬영 문장 20개다(`frontend/src/capture/prompts.json`의 `fixed`, 설정 `OLKAVS_PHRASE_FILE`).
- `margin`이 `OLKAVS_PHRASE_MIN_MARGIN`(임시값 0.5) 이상이고 1등 점수가 `OLKAVS_PHRASE_MIN_SCORE`(임시값 -3.45) 이상이면 `accepted=true`다. 화면에는 자유 인식 아래에 "지정 문장 모드"로 표시한다. 기준 미달이면 "목록에서 고르지 못했습니다"와 가장 가까운 문장을 흐리게 보여 준다.
- 자유 인식 결과와 `[인식 불가]` 판정은 바뀌지 않는다. 업로드 경로(`/api/upload`), 여러 창으로 나뉜 긴 녹화, 일부가 입술 검출 실패인 녹화는 후보를 계산하지 않는다. 업로드 화면에서 고른 WebM은 녹화 경로로 처리하므로 지정 문장 모드가 적용된다.
- 후보 20개를 모두 정렬할 수 없는 짧은 입력(45프레임 미만, 약 1.5초)은 고르지 않는다. 후보가 줄면 짧은 문장끼리 겨루어 점수 차이가 부풀기 때문이다. 측정한 목록 클립의 입력은 모두 이보다 길다.
- 후보 계산이 실패하거나 목록을 읽지 못해도 자유 인식은 그대로 끝난다.
- 새 학습은 없다.

## 측정 결과 (실제 서비스 경로, 100건 모두 완료)

| 입력 | 1등이 정답 | 1·2등 차이 중앙값 | 범위 |
|---|---:|---:|---|
| 목록 문장, 소리 내어 | 38/40 | 1.56 | 0.14~3.82 |
| 목록 문장, 소리 없이 | 40/40 | 1.71 | 0.20~3.77 |
| 목록 밖 자유 문장 | 해당 없음 | 0.10 | 0.01~0.61 |
| 말하지 않기 (10개 중 모델까지 간 3개) | 해당 없음 | 0.15 | 0.06~0.29 |

말하지 않기 10개 중 7개는 입 움직임 판정에서 `[발화 없음]`으로 끝나 모델까지 가지 않았다.

| 차이 기준 | 점수 기준 | 목록 80개 중 표시 | 표시 중 오답 | 목록 밖 자유 문장 10개 중 잘못 표시 | 말하지 않기 10개 중 잘못 표시 |
|---:|---:|---:|---:|---:|---:|
| 0.3 | 없음 | 73 | 0 | 3 | 0 |
| 0.4 | 없음 | 71 | 0 | 2 | 0 |
| 0.5 | 없음 | 70 | 0 | 1 | 0 |
| **0.5** | **-3.45** | **70** | **0** | **0** | **0** |
| 0.7 | 없음 | 65 | 0 | 0 | 0 |
| 1.0 | 없음 | 58 | 0 | 0 | 0 |

점수 기준 -3.45는 목록 문장 80개의 최저 점수(-3.40)와 목록 밖 자유 문장 10개의 최고 점수(-3.50) 사이다. 위 값은 같은 100클립을 보고 고른 임시값이고, 목록 밖 자유 문장 0건도 이 자료에 맞춘 결과다. 표는 저장된 차이·점수로 다시 계산했다(100건 측정 때 서버 차이 기준은 0.4였고 차이·점수 값 자체는 기준의 영향을 받지 않는다). 다른 참가자의 파일럿 영상으로 다시 정한다.

회차를 나눠 보면, 1회차 오답의 차이는 0.231이고 2회차 오답의 차이는 0.21이다. 다른 회차에서 기준을 정해도 기준 0.5를 넘는 오답은 없다.

| 평가 회차 (목록 40개) | 표시, 전부 정답 | 인식 불가(고르지 못함) |
|---:|---:|---:|
| 2회차 | 37 | 3 |
| 1회차 | 33 | 7 |

## 같은 자료의 자유 인식

영상 전체를 넣은 일괄 평가(`scripts/pilot_evaluate.py`, 앞뒤 무음을 자르지 않음) 기준이다.

| 입력 | hybrid 문자 오류율 | CTC 문자 오류율 | 완전 일치 |
|---|---:|---:|---:|
| 목록 문장, 소리 내어 | 77.89% | 68.99% | 0/40 |
| 목록 문장, 소리 없이 | 74.33% | 67.66% | 0/40 |
| 자유 문장 | 96.36% | 83.03% | 0/10 |

- 입술 검출 100/100, 길이만 보는 기준선 3/40·3/40(소리 내어·소리 없이), 우연 1/20.
- AI Hub 문장이 새 문장보다 hybrid 기준 14~17포인트, CTC 기준 11~15포인트 낮다(학습 문구 효과일 수 있다).
- 서비스 경로에서 자유 인식 confidence가 0.75 이상인 목록 클립은 22/80이다. AI Hub로 정한 이 기준은 웹캠에서 대부분을 `[인식 불가]`로 만든다. 다른 참가자 영상으로 함께 다시 본다.

## 한계

- 한 사람(P01) 자료이고, 그 사람은 문장을 여러 번 읽은 조정용 참가자다. 처음 보는 사람 성능이 아니다.
- 후보 20개, 클립마다 짧은 문장이라는 조건의 수치다. 후보가 늘면 정확도가 떨어질 수 있다.
- 목록 밖 발화 자료는 10개뿐이라 잘못 표시되는 비율의 근거가 약하다.
- 지정 문장 모드 결과는 자유 대화 인식 성능이 아니다. 보고할 때 구분한다.
