# 10단계 — 신규 화자 추가 학습과 성능 비교

작성일: 2026-10-07. D: 원본 재확보 후 진행 중인 새 실행 계획의10단계다.

**10단계 완료: 실제 확대 학습·최종 평가·독립 검산을 마쳤으며, 이번 조건에서는 성능이 악화됐다.** 신규 모델2개를 총6,400회 학습했고 기존 대조군2개와 함께1,140개 조건별 추론 결과를 평가했다. 실행·입력·집계 오류가 발견된 것은 아니며, 확대 모델이 좋은 인식 성능을 얻지 못한 결과를 그대로 보존했다. 서비스 가중치는 교체하지 않았다.

## 실제 성능 결과

아래는 두 시드 각각의 CER를 산술평균한 값이다. CER는 문자 오류율이며 낮을수록 좋다. 95문장을 합친 단일 점수로 서로 다른 평가 집단을 섞지 않았다.

| 정상 영상 평가 | 기존441 | 확대510 | 확대−기존 |
|---|---:|---:|---:|
| 기존 화자의 다른 녹화71문장 | 81.65% | 92.66% | +11.02%p |
| 새로운 화자24문장 | 88.05% | 96.31% | +8.26%p |
| 공백 제외 중복1개를 뺀 신규23문장, 보조 | 88.16% | 96.27% | +8.11%p |

악화는 두 시드 모두에서 나타났다. 기존71은 시드42에서81.32→92.46%, 시드43에서81.97→92.87%였다. 신규24는 각각86.58→96.51%, 89.53→96.11%였다. 정상 조건의 완전 일치 문장 수는 네 모델 모두 기존71에서0/71, 신규24에서0/24였다. 추론 실패는 전체1,140행에서0건이다.

신규24의 평균 WER는120.40→100.00%로 낮아졌지만 CER와 완전 일치는 개선되지 않았다. WER가100%에 이르고 출력의 단어 구성이 달라졌으므로, WER 하나의 감소를 인식 개선으로 주장하지 않는다. CER96.31%를 단순히 빼서 ‘정확도3.69%’라고 해석하는 것도 적절하지 않다.

## 시간 순서 대조와 출력 분석

표의 값은 **대조 조건 CER−정상 CER**의 두 시드 평균이다. 양수이면 정상 영상의 오류율이 더 낮다.

| 평가 집단·모델 | 정지−정상 | 섞기−정상 |
|---|---:|---:|
| 기존71·기존441 모델 | +14.44%p | +8.19%p |
| 기존71·확대510 모델 | +1.29%p | +0.94%p |
| 신규24·기존441 모델 | +10.47%p | +11.48%p |
| 신규24·확대510 모델 | −0.87%p | −0.40%p |

확대 모델에서는 정상 시간 순서의 이점이 크게 줄었다. 신규24에서는 정지·섞기 조건의 오류율이 오히려 소폭 낮았으며, 전체 오류율 자체도 약96%로 높다. 이번 결과가 입술 움직임 학습의 개선을 보여주지는 않는다.

악화 후 저장된 출력에 대해 **사후 기술통계**도 계산했다. 공백을 뺀 신규24 예측 문자 중 ‘아’의 비중은 기존 모델의20.25%/16.97%에서 확대 모델의74.96%/73.58%로 증가했다. 같은 문자가5번 이상 연속되는 문장은 기존1/24·0/24에서 확대23/24·24/24로 늘었다. 확대 모델의 정상 출력이 빈 문장은 없었다. blank가 프레임 argmax로 선택된 비율은63.44%/64.84%이며 이는 blank의 사후확률을 뜻하지 않는다.

마지막100회 평균 CTC 손실도 기존2.211/2.127보다 확대2.612/2.677로 높았다. 두 군은 학습 문장 구성이 다르므로 이 값만으로 원인을 확정할 수 없다. 현재 확인한 것은 **반복 출력 증가, 높은 전사 오류, 정상 시간 순서 이점 감소**다. 특정 영상의 손상, 라벨 오류, 특징 손실의 충돌 중 어느 하나가 원인이라고 단정하지 않는다.

## 이번 비교의 질문

기존441문장에 새로운12명의69문장을 추가하면, 같은 학생 모델과 같은 업데이트 횟수에서 다른 화자의 문장 인식이 개선되는지 확인한다. 기존의 직접 구현한 `lipnet-compact-v1`을 유지한다. RGB 입술 영상의3D-CNN 특징을256차원으로 투영하고, 양방향2층 LSTM과 공백·blank를 포함한69개 출력 클래스로 CTC를 학습하는 구조다.

학습 방식도 기존 `B_feature`와 같다. 정답 전사의 CTC 손실에 고정된 시각 교사 특징과의 거리를 더한다. 256→512 학습용 선형 어댑터를 사용하며, 교사 신경망·음성·문자 디코더는 학습 과정에서 실행하지 않는다. 교사 특징은 앞 단계에서 저장한 파일을 읽는다. 이번 실험은 자료 확대 효과를 보는 것으로, 새로운 구조나 CTC 단독 학습과의 재비교는 아니다.

|---|---|---|

이전5단계의 B_feature 두 최종 모델을 대조군으로 재사용한다. 과거 독립 감사에 고정된 계획·결과·체크포인트와 현재 파일이 같은지 확인했고, 새 로더로 읽은 기존441개 텐서가 당시 픽셀·토큰·특징 해시와 모두 일치했다. 현재 GPU 실행 환경 및 새 초기화의 전체 상태도 같았다. 대조군을 이번에 다시 학습했다고 집계하지 않는다. 확대군 두 모델만 새로 총6,400회 업데이트한다.

각 모델의 문장 제시 횟수는6,400회로 같다. 다만 문장 길이와 자료 수가 달라 처리 프레임·실행 시간·문장당 반복 수는 동일하지 않다. 기존군은 각 문장을14~15번, 확대군은12~13번 본다. 확대군의 사전 고정 순서는 시드42에서 기존5,528회/신규872회, 시드43에서 기존5,529회/신규871회를 제시한다. 더 나은 시드나 중간 체크포인트를 골라 성능을 높여 보고하지 않는다.

## 자료 경계와 평가

- 학습: 기존441+잠정69만. 전사가 불확실해 보류한27개는 학습에서 제외한다.
- 기존 개발71: 기존 학습과 같은8명의 다른 녹화이며 이미 여러 실험에서 평가했다.
- 신규 개발24: 학습과 겹치지 않는3명이며, 전사 자동 비교가 불일치한 문장도 모두 유지한다.
- 신규23 보조 결과: 공백을 제외하면 학습 문장과 같은 C059_A_002_036 한 개만 사전에 정한 대로 제외해 재집계한다. 원래24개 결과도 함께 보고한다.

두 대조군과 두 확대군의 최종 모델을 모두 같은 코드로 다시 평가한다. 각 모델은95문장×정상/정지/순서 섞기3조건을 추론하므로 총1,140개 결과를 저장한다. 신규23개 결과는 신규24개 결과에서 재집계하며 별도의 추론이나 분할 변경이 아니다.

출력은 프레임 argmax→CTC 중복 축약→blank 제거→한국어 자모 조합 순서로 복원한다. 잘못된 자모는 U+FFFD 오류 문자로 남기며 원시·축약 토큰도 저장한다. 기존 대조군의 old71 결과는5단계 보정 평가와 원시 토큰·문자열·오류 수·시간축 조작이 정확히 재현되는지 확인한다. 이전의 엄격한 정답용 디코더로 얻은 수치를 이번 수치와 섞지 않는다.

주 지표는 내부 공백을 포함한 NFC 문자 CER이며 WER, 완전 일치 문장 수, 공백 정규화 지표, 화자별 결과를 함께 보고한다. 오류율은 낮을수록 좋고, ‘확대−기존’ 차이가 음수이면 개선이다. 정상 영상과 정지·순서 섞기의 차이는 시간에 따른 입술 움직임을 활용하는지 확인하는 진단이다.

## 사전 검증과 기록

혼합 로더21개, 학습 계약9개, 평가17개의 테스트47개가 통과했다. 실제 학습510개·개발95개 캐시를 검사했고, 별도 감사 코드가 학습용510개 픽셀·정답·특징을 직접 읽어 두 시드의 데이터 해시를 재계산했다. 기존군과 확대군의 각각 고정된 해시가 일치했다. 학습 계획·실행 코드·평가 규약은 첫 업데이트 전에 고정했다.

새 결과는 `experiments/expansion_step10_20261007/`에 저장한다. `comparison_plan.json`과`plans/seed42.json`, `seed43.json`이 실행 계약이며, `logs/`와`runs/`가 실제 이력·100회 간격 복구 상태를 담는다. 이전 단계 입력·특징·계획·가중치를 덮어쓰지 않는다.

실제 확대 학습은 시드42가822.63초, 시드43이798.28초로 총약27.02분이었다. 각각739,906/740,147프레임을 반복 처리했으며 합계1,480,053프레임이다. 최종 모델 선택용 조기 종료나 중단 복구는 없었다. 최대 GPU 할당 메모리는약500.26MiB였으며, CUDA 문맥 등을 포함한 장치 전체 사용량을 뜻하지 않는다. 각 실행에서100회마다32개씩, 신규64개 복구 체크포인트를 저장했다.

전체 코드 검증은 혼합 로더21+학습 계약9+평가17+집계21+독립 감사41=**109개 테스트 통과**다. 최종 독립 감사는 대조군까지 포함한128개 체크포인트의 바이트·저장 상태, 마지막 모델·어댑터·Adam, 신규6,400회와 재사용6,400회 이력 구분을 확인했다. 실제 추론1,140행과 보조 재집계276행, 두 시드 평균·화자별 수치·실제 노출량·시간·메모리·손실 집계도 통과했다. 기존 대조군의 old71 출력426행은 과거 보정 평가를 정확히 재현했다. 사후 출력 통계도 별도 계산으로 재검산했다.

## 해석할 때 남는 한계

신규69개는 같은 ASR의 두 전사가 공백 제외 일치한 잠정 후보다. 전체 발화·경계를 사람이 승인한 자료라고 주장하지 않는다. ‘부 준비하고 있어’와 ‘영 여행 영상을’의 두 답변은 계속 보류 상태이며 이번 후보에 넣지 않았다. 일부 신규 영상의 점상 질감 관찰도 유지한다.

두 개발군은 검수·과거 실험 이력이 있어 손대지 않은 최종 시험 자료가 아니다. 두 시드와 작은 개발 집단의 차이를 통계적 확증이나 웹캠 실사용 정확도로 해석하지 않는다. 라벨의 입술 좌표로 준비한 문장 단위 영상 결과와, 실제 웹캠의 얼굴 검출·입술 자르기·발화 구간 분할 성능도 구분해야 한다. 추가 자료 다운로드와 서비스 모델 교체는 이번 단계 범위에 없다.

## 다음 단계 제안

다음11단계는 **반복 출력의 원인을 분리하는 작은 학습 진단 실험**으로 진행하는 것이 타당하다. 기존 자료와 신규 자료에서 학습 전용 소집합을 고정하고, 문장을 외울 수 있는지부터 확인한다. 같은 입력·초기 상태·업데이트 조건에서 CTC만 쓰는 경우와 특징 손실을 함께 쓰는 경우를 비교하면 전사 학습과 특징 전달의 영향을 구분할 수 있다. 학습 문장별 CTC 손실, 정답 길이 대비 출력 길이, 자모·문자 분포, 정상/정지/섞기 차이를 함께 기록한다.

검증할 가설에는 확대 후 기존 문장의 반복 노출 감소, 새 화자·영상 분포에 대한 최적화 부족, CTC와 특징 전달의 상호작용이 있다. 라벨·입력 대응의 불확실성도 계속 고려하되 이번 결과만으로 특정 자료를 잘못됐다고 판정하지 않는다. 진단 집단·학습량·중단 기준을 먼저 고정하고, 결과에 따라 본학습 규약을 새 버전으로 수정한다. 이번 두 확대 모델이나 과거 결과를 덮어쓰지 않는다.

현재 보유 자료로 이 진단을 진행할 수 있어 다음 진단을 위한 추가 다운로드는 필요하지 않다. 이번10단계의 악화는 현재 설정에 대한 실험 결과이며, 립리딩이나 기존 학생 구조 전체의 가능성이 없다는 결론은 아니다. 웹캠에서 상대방의 말을 텍스트로 복원하는 최종 목표는 아직 달성하지 못했다.
