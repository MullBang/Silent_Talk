# 새 실행계획 2단계 — 고정 8문장 입력·교사 특징 파일럿

작성일: 2026-10-07. [1단계 D: 데이터 연결](01_D드라이브_데이터연결_결과.md)에 이어 실행한 결과다.

## 결과와 의미

**고정된 학습 8문장의 입력 준비, D: 출처·프레임 대응 검산, GPU 교사 특징 추출을 모두 완료했다.** 현재 PC의 RTX 3080에서 이 파일럿을 처리할 수 있으며, 추가 자료 다운로드나 Colab 이용은 이번 작업에 필요하지 않았다.

이번에 생성한 것은 학생 모델을 학습시킬 때 참고할 **프레임별 512차원 시각 특징**이다. 공개 OLKAVS 모델의 시각 특징 추출부만 고정해서 사용했다. 자체 경량 모델을 공개 모델로 교체하거나 새 모델 가중치를 학습한 작업은 아니다. 특징을 이용했을 때 한국어 인식이 개선되는지는 앞으로의 대조 실험에서 확인한다.

## 입력을 준비한 방법

기존 512문장 계획과 학습441/개발71 분할을 유지했다. 8문장은 결과를 보고 다시 고르지 않고 기존 계획에 고정된 문장을 사용했다. 모두 학습 자료이며, 개발·최종 평가 문장의 교사 특징은 만들지 않았다.

D: TAR에서 녹화 한 개의 영상과 라벨만 임시 복사하면서 SHA-256을 검사하고, 1단계 adapter로 기존 전처리 함수를 호출했다. 음성은 읽지 않았다. 처리가 끝난 원본 임시 사본은 삭제했으며, 결과 입력과 특징만 프로젝트에 남겼다.

학생 입력은 기존 20% 여백의 RGB 입술 영상, 교사 입력은 여백 0의 BGR 입술 영상이다. 두 입력의 색상 순서와 영역 크기가 다르므로 결과 이미지 자체가 같아야 하는 것은 아니다. 대신 **동일한 원본 프레임 번호와 그 프레임의 원본 픽셀 해시가 대응하는지** 검증했다.

교사는 원본 프레임을 순서대로 사용하고 양쪽에 실제 문맥 프레임 2개씩을 포함한다. 이번 8문장은 물리적 영상 경계 때문에 문맥이 잘린 경우가 0개였다. 전체 교사 입력 구간의 평균·표준편차로 한 번 정규화한 뒤 한 번에 처리하고, 학생 프레임과 같은 원본 번호의 특징을 정확히 선택했다. 길이 비율 보간이나 임의의 프레임 복제는 사용하지 않았다.

첫 실행과 이후 실행의 차이가 있으므로 빠른 재실행 시간만으로 실시간 웹캠 성능을 주장하지 않는다. 현재 웹캠 프로그램 전체를 측정한 작업도 아니다.

## 품질·무결성 검사

- 독립 입력 검사기가 학생1,543프레임·교사1,888프레임의 인덱스, 대응 행, 시각, 문맥, 배열 해시, 정답 토큰, D: TAR 출처를 확인했다.
- 기존512문장 계획과 분할·시간 보정값이 유지됐고, 기존4문장449프레임 재현 대조군도 확인했다.
- 각 문장의 학생 첫·중간·마지막 이미지와 대응 교사 중간 이미지, 총32장 표본을 시각적으로 확인했다. 입술이 포함되어 있고 회전·빈 화면·배경만 잘린 모습은 보이지 않았다. 모든 프레임의 사람 검수나 실제 전사 검증을 뜻하지 않는다.
- 교사의 `encoder.front.` 부분만 엄격하게 적재했다. 변수11,218,176개, 상태 항목130개가 대상이며 나머지 전체 체크포인트 항목은 모델에 적재하지 않았다. 자막 디코더는 생성하지 않았다.
- 교사를 평가 모드·FP32·기울기 비활성 상태로 실행했고, 모든 문장 전후에 파라미터와 버퍼의 해시가 같았다.
- 모든 특징이 유한한 값이며 영벡터가 없었다. 문장마다512개 차원 모두 시간에 따른 변화가 있었으며, 전체 구간이 같은 벡터로 고정된 현상은 없었다. 이 검사는 특징이 유용한 언어 정보를 담는지까지 증명하지 않는다.
- 첫 입력을 한 번 더 실행한 결과는 비트 단위로 같았다. 최대 절대 차이는0이었다.
- 별도 특징 검산이 저장 NPZ와 기록, 특징값 해시, 입력 프레임 대응, FP32·유한값·시간 변화, 교사 상태, 측정 집계를 확인했다. 이 검산에서는 GPU를 다시 실행하지 않았다.
- 입력 검산 오류 탐지18개, 새 교사 파일럿 검사6개, 기존 교사 규약 회귀 검사9개로 총33개 테스트가 통과했다.

전체 공개 모델의 원래 데이터 제작 파이프라인을 바이트 단위로 재현했다는 주장은 하지 않는다. 이번 경로는 기존 시간 보정과 실제 문맥 프레임을 사용해 특징 전달에 맞게 구성한 입력이다. 원본 정답의 언어적 정확성, 전체 입술·음성 동기, 웹캠 환경 적응, 최종 인식률은 별도 과제다.
