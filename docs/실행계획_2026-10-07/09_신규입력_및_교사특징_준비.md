# 9단계 — 신규 120문장 입력과 잠정 학습 후보의 교사 특징 준비

작성일: 2026-10-07. 이전 개선 과정의 9단계가 아니라, D: 원본 재확보 후 진행 중인 **새 실행 계획의 9단계**다.

**실제 입력 120개와 교사 특징 69개를 생성하고 독립 검산을 완료했다.** 기존 441개와 신규 후보 69개를 연결한 510문장 인계 목록도 만들었다. 학생 모델의 학습·성능 측정·서비스 가중치 교체는 이번 단계에서 실행하지 않았다.

## 무엇을 준비했는가

| 신규 자료의 역할 | 문장 수 | 학생 입력 프레임 | 저장한 내용 |
|---|---:|---:|---|
| 잠정 학습 후보 | 69 | 8,455 | 학생 영상 입력, 교사 영상 입력, 정렬한 512차원 시각 특징 |
| 학습 포함 보류 | 27 | 3,426 | 학생 영상 입력만 |
| 개발 평가 | 24 | 3,228 | 학생 영상 입력만; 전사 일치 여부로 제외하지 않음 |
| 합계 | 120 | 15,109 | 원래 학습96/개발24 구분 유지 |

후보69는 **원래 학습 분할에 속하고, 7단계 두 전사가 정규화·공백 제외 비교에서 모두 목표 전사와 일치한 문장**이다. 같은 ASR 모델의 두 실행 결과이므로 독립적인 정답 검증은 아니다. 69개 중 공백까지 양쪽 모두 일치한 것은49개이며 나머지20개에는 공백 차이가 있다. 숫자·반복·어려운 발화를 덜 포함하는 선택 편향도 남는다.

이는 불확실성을 명시한 실험을 준비하기 위한 잠정 기준이다. 사람의 전체 전사·문장 경계 승인으로 승격하지 않았고, 기존 `training_ready=false`도 유지했다. 입력이 준비되었다는 것과 검수가 모두 끝났다는 것은 다르다.

사용자가 확인한 ‘애쓰는’ 한 번은 7단계 정답 규약 그대로 입력 토큰에 연결했다. 이 문장은 보류27에 속한다. ‘떠넘겨 떠넘긴 채’ 확인은 원래 반복 표현을 유지하는 근거로 보존했으며, 역시 전체 문장 승인이나 후보 편입으로 확대하지 않았다.

## 영상과 교사 특징의 연결

1. D: TAR에서 필요한 녹화의 영상·라벨만 한 번에 하나씩 임시로 꺼내 파일 길이와 SHA-256을 검사했다. G: 사본과 미리보기 영상은 사용하지 않았다.
2. 6단계에서 확인한 시간 보정과 원본 프레임 번호를 재사용했다. 실제 약29.97fps 원본에서 25fps 학생 시간축에 해당하는 가장 가까운 프레임을 선택했다. ASR의 단어 시각으로 경계를 바꾸지 않았다.
3. 학생 입력은 입술 좌표에20% 여백을 주어 RGB 96×96으로 저장했다. 모든120문장의 목표 토큰과 CTC 길이 조건을 연결했다.
4. 후보69만 교사용 BGR 96×96 입력을 저장했다. 교사는 여백0, 원본 시간축과 양쪽 실제2프레임 문맥을 사용한다. 원본 전체 창의 평균·표준편차로 정규화해 기존 실험과 동일한 입력 규약을 유지했다.
5. 기존 고정 교사의 `encoder.front: Resnet2D_front(3,512)`만 FP32로 실행했다. 원본 시간축10,444프레임의 특징에서 학생 프레임 번호에 해당하는 행을 골라 총8,455×512 특징을 저장했다.

음성, 텍스트 전사, 교사의 문자 디코더는 특징 추출 모델 입력에 넣지 않았다. 교사의 가중치도 학습하지 않았다. 향후 직접 만든 학생 모델이 CTC 학습과 시각 특징 전달을 이용할 수 있도록 준비한 자료이며, 이번에 새 립리딩 모델이 학습된 것은 아니다.

보류27·개발24는 전처리 중 대응 검사에 쓰인 임시 교사 배열을 제거하고 학생 배열만 저장했다. 교사 신경망에는 이51개를 전달하지 않았으며 교사 특징 파일도 없다.

## 검증한 범위

- **선정 검산:** 후보69/보류27/개발24, 토큰과 CTC 길이, 기존512와 신규120의 ID·화자·녹화·원본 파일 해시 중복 여부를 재계산했다. 기존 자료와 신규 자료의 해당 중복은 없다.
- **전체 입력 독립 검산:** 120개 NPZ의 배열·메타데이터·토큰·프레임 번호·시간·라벨 좌표·역할을 확인했다. 학생15,109개와 교사10,444개 프레임 추적 기록, 6단계 PNG360장의 픽셀 비교가 통과했다.
- **대표 원본 독립 재생성:** C045_A_007을 D: TAR에서 별도로 읽고 SHA를 확인했다. 원본605프레임을 직접 디코딩하여 학생539장·교사353장의 입술 영역과 원프레임 해시를 다시 계산했고 저장 결과와 완전히 일치했다. 나머지29개 녹화는 이 감사에서 전체 재디코딩하지 않았다.
- **교사 재현성:** 첫 입력의 재실행 출력이 비트 단위로 동일했다. 매 실행 전후 가중치 상태 해시는 같고, 이전441개 특징 추출 때의 교사 상태와도 일치했다.
- **저장 특징 독립 검산:** 69개 전부의 FP32·8,455×512 차원·유한값·0이 아닌 벡터·학생/교사 프레임 대응·입출력 해시를 확인했다. 원시 픽셀의 평균·표준편차를 별도로 재계산한 차이는 각각 최대 약0.0000104/0.00000181이었다. 이 감사는 GPU 모델을 별도로 다시 실행한 검증은 아니다.
- **기존 자료 보존 확인:** 기존512개 입력 및441개 특징 파일을 실제로 다시 해시 검사하고 참조했다. 파일과 원래 딕셔너리를 복사하거나 덮어쓰지 않았다.

코드 계약 테스트는 입력 생산21개, 입력 독립 감사24개, 교사 생산11개, 특징 감사4개로 총60개 통과했다. 선정·입력·특징 감사는 모두 `passed`다.

6단계에서 이미 본 입술 표본과 이번 픽셀이 같다는 결과를 새로 전체 영상을 눈으로 검수했다는 뜻으로 해석하지 않는다. 당시 C630·C646·C658·C675의32문장 표본에는 강한 점상 질감이 관찰됐고, 이 중22개가 이번 후보에 포함된다. 입술 위치는 확인했지만 전체 화질, 질감의 원인, 학습에 미치는 영향은 아직 확정하지 않았다. 임의 필터링이나 영상 보정은 적용하지 않았다.

신규 후보 `lip_J_1_F_02_C075_A_003_014`와 신규 개발 `lip_J_1_F_05_C059_A_002_036`는 **공백을 제외하면 같은 문장**이다. ‘고객 응대’/‘고객응대’처럼 띄어쓰기가 달라 원문 문자열 자체의 완전 일치는 아니다. 다음 평가는 개발24개 전체 결과와 이1개를 제외한23개 결과를 함께 제시한다. 원래24개 분할을 수정하거나 불일치 항목을 빼서 평가하지 않는다.

기존71과 신규24를 합쳐 전부 ‘학습에서 보지 않은 화자’라고 부르지 않는다. 개발 자료에는 이미 검수와 과거 평가 이력이 있으므로 손대지 않은 최종 시험 자료라고 주장할 수도 없다. 공개 교사 모델의 사전학습 자료와의 중복 여부 역시 미확인이다.

**다음10단계는 혼합 자료 로더와 학습 실행 계획을 고정한 뒤 자료 확대 비교로 진행한다.** 기존441개만 쓰는 대조군과 신규69개를 추가한510개 실험군을 같은 출발 가중치·계산량 조건에서 비교하도록 설계한다. 구체적인 초기 상태·시드·업데이트 수·전사 사용 규칙을 실행 전에 새 계획에 기록해야 한다. 기존5단계 실행기는441/71에 고정돼 있으므로510개에 그대로 적용하지 않는다.

기존 개발71, 신규 개발24, 공백 제외 중복을 뺀 신규23의 CER/WER·완전 일치율을 구분하고 정상 프레임/정지 영상/순서 섞기 대조를 유지한다. 잘못된 자모도 오류 문자로 보존하는 예측 복원 규칙과 원시 토큰을 저장한다. 숫자를 얻기 전에는 자료 확대가 성능을 개선했다고 결론 내리지 않는다. 이후에도 웹캠 입력과 학습 입력의 차이를 별도로 검증해야 한다.
