# 15단계 — 새로운 문장을 구별하기 위한 학습 구성 개선

2026-10-07 완료. **학습 자료와 비교 실험 설계를 개선했고, 통합 테스트81개와 독립 캐시 검증을 통과했다. 실제 추가 학습과 인식 성능 검증은16단계에서 실행한다.** 자체 모델 구조와 서비스 가중치는 유지한다.

14단계에서는 정답보다 학습 문장이나 실제의 틀린 출력에 높은 확률을 주는 문제가 확인됐다. 이번에는 같은 화자가 여러 내용을 말하는 자료를 늘리고, 적은 문장을 반복하는 학습과 직접 비교할 수 있도록 구성했다. 단순히 더 큰 자료를 넣으면 해결된다고 가정하지 않는다.

## 기존24문장을 그대로 늘리지 않은 이유

기존 혼합8화자 중 일부는 평가 문장을 제외하면 사용 가능한 문장이4개뿐이었다. 억지로 균등48~72개를 만들려면 검증용 녹화의 다른 문장까지 학습에 넣어야 해, 다른 녹화로 평가한다는 조건이 깨졌다.

따라서 자료가 충분한 기존8화자 **C002·C004·C017·C032·C282·C293·C297·C312**로 새로운 대조24문장과 확대72문장을 구성했다. 두 군 모두 처음부터 학습할 계획이다. 이전12단계의24문장 모델을 새 대조군으로 재사용하지 않는다.

전체510개 후보를 검토했고, 이번 범위에 맞는 기존8화자 자료에서 과거 진단 녹화와 중복 전사를 제외하니368개가 남았다. 신규 잠정 자료는 목록과 상태를 유지하되 이번 비교에 넣지 않았다.

대조24개는 확대72개에 모두 포함된다. 양쪽의 화자·학습 녹화와 녹화 비중2:1이 같아, 이번에 비교하려는 차이는 **같은 녹화들 안에서 서로 다른 문장을 더 많이 학습하는 효과**다. 검증용16개는 학습 녹화와 완전히 분리했다. 과거 한 녹화 중심의 구성과 달라졌지만, 녹화 수 증가만의 효과를 별도로 측정하는 실험은 아니다.

선정은 성능이나 출력 내용을 보고 고르지 않고, ID에 대한 고정 해시 순서로 수행했다. 선택·제외 이유218건을 남겼으며, 선택 과정에서 다른 선택 문장과 전사가 같은 C312_A_003_012를 건너뛰었다.

### 자료가 섞이지 않도록 한 처리

- 12단계 내부 검증8개와13단계 진단12개의 합집합14개가 속한 **녹화 전체**를 제외했다. 녹화 이름뿐 아니라 원영상·라벨 SHA도 비교했다.
- 원래 개발95개와 보류27개의 전사와 같은 학습 후보도 제외했다. 예를 들어 C004_A_005_004는 기존 개발 문장과 같은 전사였다.
- 선택88개의 정규화 전사는 모두 다르다. 같은 원영상의 시간구간·학생 프레임 중첩도 차단했다.
- 기존 청취 대기2건, 원래 개발·보류·시험 역할과 사람 검수 상태는 유지했다. 자료 선택을 사람의 전사 승인으로 간주하지 않았다.

검증16개는 이번 학습에 들어가지 않을 같은 화자의 다른 녹화다. 더 오래된 실험에서는 학습 후보였으므로, 손대지 않은 최종 시험이나 새로운 화자 성능으로 부르지 않는다.

## 확정한 학습·평가 규약

자체 모델에 시각 특징 학습을 더하는 기존 **B_feature** 방식으로, 두 초기값42/43 각각에서 대조24와 확대72를 학습한다. 총4회다. 자료 구성 효과를 비교하는 것이므로 A/B 방식 비교를 다시 추가하지 않았다. B가 일반화에 더 우수하다고 확정한 것은 아니다.

| 항목 | 고정 설정 |
|---|---|
| 초기화 | 매 실행 처음부터 시작, 같은 초기값의 두 학습군은 동일한 초기 상태 |
| 모델 | 기존 lipnet-compact-v1 학생 모델과 특징 연결층 |
| 손실 | CTC1 + 저장된 시각 교사 특징 손실1 |
| 업데이트 | 실행당3,600회, 총14,400회 |
| 업데이트당 자료 | 서로 다른 화자2명의 문장, 두 학습군의 화자 순서 동일 |
| 문장당 노출 | 대조24는300회, 확대72는100회 |
| Adam | betas0.9/0.999, eps1e-8, weight decay0, gradient clip1 |
| 학습률 | 1~2400회0.001 → 2401~3000회0.0003 → 3001~3600회0.0001 |
| 주 평가 | 최종3600회 모델의 공통 검증16문장 CER |
| 중간 평가 | 검증1200/2400/3000/3600, 학습 문장2400/3600 |
| 대조 입력 | 최종 모델의 검증16 정지·프레임 순서 섞기 |
| 추가 진단 | 과거14문장 정상 입력, 현재 학습한 화자8행/학습하지 않은 화자6행 분리 |

학습률 감소는12단계의 후반 불안정성을 줄여 보기 위한 공통 설정이다. 학습률이 유일한 원인이라고 확인한 것은 아니며, 그 효과만 따로 측정하는 실험도 아니다. 변경된 설정은 양쪽에 동일하게 적용하고 새 대조군과 비교한다.

같은 업데이트 수라도 전체 연산량은 완전히 같지 않다. 실행당 학생 프레임 노출은 대조731,400개, 확대748,400개로 약2.32% 차이다. 네 실행 합계는2,959,600프레임·28,800문장 노출이다. 이 비교는 **고정 업데이트 예산에서 서로 다른 문장 수와 반복 횟수의 배분을 바꾸는 실험**이며, 같은 epoch·FLOPs·실행 시간 비교가 아니다.

### 결과 판단과 실행 상한

두 초기값 각각에서 `확대군 CER − 대조군 CER`를 계산하고 두 차이의 평균을 함께 보고한다. 둘 다 감소하고 평균5%p 이상 감소하며 실패가 없을 때 추가 확대를 검토한다. 이5%p는 미리 정한 실용적인 후속 실험 기준이며 통계적 유의성이나 실사용 성공 기준이 아니다. 기준을 못 넘겨도 실제 수치와 남은 문제를 그대로 보고한다.

유리한 중간 체크포인트만 선택하지 않고 최종3600으로 비교한다. 학습 문장을 잘 맞히는 것만으로 성공 판정하지 않는다. WER·문장 완전 일치·자모 오류·화자별 결과·시간 순서 대조도 함께 기록한다.

계획된 신경망 평가는824행이다. 학습 정상384, 검증 정상256, 검증 정지·섞기128, 기존 진단 정상56행으로 분모를 고정했다. 체크포인트는600회마다 총24개를 계획한다. 실행당35분·전체150분의 상한, 시작 시5GiB 여유 공간, 자동 학습 연장 금지를 명시했다. 비정상 손실·자원 실패·시간 초과는 미완료로 남기고, 같은 전체 상태에서 상한 내1회 재개만 허용한다.

## 저장공간과 현재 실행 범위

기존 학생 입력88개 **333.09MiB**, 학습용 교사 특징72개 **13.93MiB**를 그대로 참조한다. 약347.03MiB는 이미 존재하는 파일들의 크기이며 새로 복제한 양이 아니다. D:/G: 영상·TAR를 다시 열거나 동기화할 필요가 없다.

자료 생성기는 이160개 파일의 SHA를 확인한다. 독립 감사에서는 학생88개 배열과 학습 특징72개 배열의 크기·토큰·프레임 대응을 확인한다. 검증용 교사 특징과 교사 영상 배열은 디코드하지 않는다. 짝입력 NPZ의 전체 파일 해시 계산은 교사 영상의 압축 바이트도 읽지만, 교사 영상 배열을 모델 입력으로 읽는 작업과 구분한다.

실제 학생 학습·모델 추론·교사 실행·다운로드·서비스 가중치 변경은 모두0회다. 새 인식 성능은 아직 측정하지 않았다.

통합 테스트81개(자료24·학습 설계27·독립 감사30)를 통과했다. 독립 구현으로 전체 메타데이터632개와 학습 후보510개, 적합 후보368개, 선정 사건218개를 재구성했다. 학생88개·학습 특징72개 배열의 토큰·프레임·정렬과 학습군 분리, 예정된4회 학습 순서·노출 수·학습률을 검증했고 기존 가중치와 출처 파일 보존을 확인했다. 과거 모델 체크포인트와 저장 확률 파일은 이번에 다시 열지 않았다. 검증 결과는 아래 완료 기록과 감사에 연결한다.

## 다음16단계
