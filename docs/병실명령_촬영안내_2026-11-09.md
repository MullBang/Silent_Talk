# 병실 명령 촬영 안내 (2026-11-09)

병실 무음 도우미의 명령 20개를 조원이 각자 찍기 위한 안내다. 아래 "조원용" 부분은 촬영 패키지(`npm.cmd run build:capture-package`)에 `병실명령_촬영안내.html`로 들어간다.

- 촬영 묶음: `ward_tune`(병실 명령 조정용, 93클립)·`ward_eval`(병실 명령 평가용, 103클립). 구성은 `frontend/src/capture/ward_prompts.json`의 `sessions`, 명령 문장은 `frontend/src/ward/commands.json`이다.
- 함정 문장과 짧은 말 목록은 촬영 화면에만 나온다. 평가 참가자가 이 안내를 읽으므로 이 문서에는 적지 않는다.
- 받은 폴더는 인식 전에 모델 없이 점검한다: `py -3.11 scripts/pilot_evaluate.py check --clips <폴더>`. 평가용 폴더는 기준값 동결 전까지 `check` 외에는 아무것도 돌리지 않는다(`roi-all`은 `ward_eval` 폴더를 `--allow-sealed` 없이는 거부한다).
- 5초에 잘린 클립은 다시 찍지 않고 메모에 적게 했다(기획 10.2의 "녹화 길이" 지표 자료). 다시 찍으면 같은 이름으로 덮어써서 잘린 클립이 사라지기 때문이다. 다시 찍기는 잘못 말함·얼굴이나 입이 화면 밖·영상 멈춤 경고 때만 한다.

# 병실 명령 촬영 안내 (촬영하는 사람용)

이 안내를 위에서부터 순서대로 따라 하면 된다. 프로그램 설치나 인터넷은 필요 없다. 촬영은 약 20분, 준비까지 30~40분 걸린다.

예전에 문장 20개를 찍어 본 사람도 이번에는 **방법이 다르다.** 한 클립이 **5초에 저절로 멈추고**, 중간에 멈출 수 없다.

## 0. 내 정보 (팀장에게 받아서 적기)

| 항목 | 적기 |
|---|---|
| 내 가명 ID | P__ |
| 촬영 묶음 | □ 병실 명령 조정용 (93클립)  □ 병실 명령 평가용 (103클립) |
| 보내는 방법 | □ USB로 직접  □ 팀장에게만 공유된 클라우드 폴더 |

- 가명 ID와 촬영 묶음은 팀장이 정해 준 그대로 쓴다. 예전 촬영과 같은 가명 ID를 쓴다.
- 파일 이름, 메시지, 메모 어디에도 실명 대신 가명 ID만 쓴다.

## 1. 준비물

- [ ] 웹캠이 있는 PC (노트북 내장 카메라도 된다)
- [ ] Chrome 또는 Edge 브라우저
- [ ] 받은 압축 파일을 **압축 풀기**한 폴더 (`웹캠촬영.html`과 이 안내가 들어 있다. 압축 파일 안에서 바로 열지 않는다)
- [ ] 영상을 저장할 **새 빈 폴더** 하나. 이름에 가명 ID를 넣는다. 예: `silent_talk_P01_ward`
  - **예전에 문장을 찍은 폴더는 쓰지 않는다.** 그 폴더를 고르면 "촬영 묶음이 다른 클립" 오류가 난다.
  - 바탕화면·문서 폴더가 OneDrive나 iCloud로 동기화되면 영상이 자동으로 인터넷에 올라간다. 그럴 때는 동기화되지 않는 곳에 만든다(Windows: `C:\silent_talk_P01_ward`).
- [ ] 조용하고 아무도 들어오지 않는 방에서 30~40분
- [ ] **조정용만**: 등받이에 기댈 수 있는 자리(뒤로 젖혀지는 의자, 또는 베개·쿠션을 받친 침대)와 노트북을 올릴 낮은 탁자(침상 테이블, 좌탁 등). 마지막 10클립에서 쓴다.

## 2. 촬영 자리 만들기 (10분)

1. **조명**: 방 불을 켜고 얼굴 **앞쪽**이 밝게. 창문을 등지고 앉지 않는다.
2. **배경**: 단순한 배경. 뒤에 다른 사람이나 켜진 TV가 없게.
3. **카메라**: 화면 위쪽 가운데, **눈높이**. 노트북이면 책을 받쳐 높인다.
4. **거리**: 얼굴과 카메라 사이 **50~70cm** (팔을 뻗었을 때 손끝 정도).
5. **화면 속 얼굴 크기**: 얼굴(이마~턱)이 화면 세로의 **1/3 이상**, 가운데.
6. **나**: 마스크·모자 벗기, 머리카락이 입을 가리지 않게, 안경은 평소대로, 껌·사탕 금지.

## 3. 프로그램 열기 (5분)

1. 압축을 푼 폴더에서 `웹캠촬영.html`을 **Chrome 또는 Edge**로 연다(오른쪽 클릭 → 연결 프로그램 → Chrome 또는 Edge).
2. 화면 맨 위에서 **이 순서대로**:
   1. **가명 ID** 입력 (예: P01)
   2. **촬영 묶음** 선택: `병실 명령 조정용 (5초 자동 정지, 93클립)` 또는 `병실 명령 평가용 (5초 자동 정지, 103클립)` 중 0장에서 받은 것
   3. **저장 폴더 선택** → 1장에서 만든 새 빈 폴더 → 브라우저가 물으면 모두 허용
   4. **카메라 열기** → 카메라 권한을 물으면 허용
3. **녹화 전 확인**:
   - [ ] 버튼에 `저장 폴더: (내 폴더 이름)`이 보인다.
   - [ ] 문장 상자 위 작은 회색 줄이 `병실 명령 조정용 · 1 / 93` 또는 `병실 명령 평가용 · 1 / 103`으로 시작한다.
   - [ ] 위쪽 주황색 글에 "5초 뒤 저절로 멈춥니다"가 보인다. 보이지 않으면 촬영 묶음을 잘못 골랐다.
   - [ ] 영상에 내 얼굴이 2장의 크기·위치로 보인다.

화면이 폴더에 바로 저장할 수 없다고 하면(노란 상자) 찍을 수는 있다. 대신 **20클립마다, 그리고 다 찍은 뒤 "찍은 클립 N개 내려받기 (zip)"** 를 누른다. 내려받기 전에 창을 닫으면 그 사이 클립이 사라진다.

## 4. 녹화 한 번 하는 법 (모든 클립 공통)

1. 화면에 나온 문장이나 지시를 **눈으로 읽고 외운다.**
2. **카메라 렌즈 쪽을 보고** 입을 편하게 다문다.
3. **스페이스바**를 한 번 누른다(또는 초록색 "녹화 시작" 버튼).
4. 영상 왼쪽 위에 빨간 **● REC 5초**가 뜨면 **바로** 말한다. 평소 대화하는 속도로, 서두르지 않는다.
5. 말이 끝나면 입을 다물고 기다린다. **5초가 되면 저절로 멈추고** 다음 순번으로 넘어간다. 중간에 스페이스바를 눌러도 멈추지 않는다.
6. **클립 끝에 스페이스바를 누르지 않는다.** 예전 문장 촬영처럼 끝날 때 누르는 버릇이 있으면 다음 클립이 준비 없이 시작될 수 있다. 다음 문장을 읽고 준비가 됐을 때만 누른다.

**다시 찍는 때 (이 셋뿐)**: 다시 찍으면 같은 이름으로 덮어써서 먼저 찍은 클립은 사라진다. 그래서 아래 경우에만 **"이전 (다시 찍기)"** 를 누르고 같은 순번을 다시 녹화한다.

- 화면 문장과 **다르게 말했다**(글자를 바꾸거나 빼먹음, 다른 문장을 말함, 말하다 웃음이 터짐).
- **얼굴이나 입이 화면 밖으로 나갔거나 가려졌다**(손, 머리카락 등).
- 저장 뒤 주황색 **⚠ 경고**에 "영상이 …ms 동안 멈췄습니다"가 떴다. 카메라를 쓰는 다른 프로그램을 끄고 한 번 다시 찍는다. ("실제 프레임이 … 적습니다" 경고는 조명을 밝게 해 보고, 그래도 같으면 다시 찍지 않고 계속한다.)

다시 찍었으면 메모에 적는다(예: `silent W07 1회차 - 글자 바꿔 말해서 다시 찍음`).

- **말이 끝나기 전에 5초가 되어 녹화가 멈췄으면 다시 찍지 않는다.** 그대로 두고 다음으로 넘어간 뒤 메모에 적는다(예: `silent W07 1회차 - 5초에 잘림`). 5초가 충분한지 재는 자료라서, 잘린 클립이 그대로 남아 있어야 한다. 다음 클립부터도 말하는 속도는 바꾸지 않는다.
- 회색 줄 끝에 `이미 저장됨(녹화하면 덮어씀)`이 보이면 이미 찍은 칸이다. 위의 다시 찍는 때에만 녹화한다.

**첫 클립을 찍은 뒤 한 번만**: 새 탭(Ctrl+T)을 열고 저장 폴더의 첫 영상 파일(`.webm`)을 **그 새 탭에** 끌어다 놓아 재생해 본다. 얼굴이 가운데에 충분히 크게, 밝게 나오는지 본다.

촬영 전에 이 표를 소리 내어 한 번, 소리 없이 한 번 읽어 본다(5분). 촬영할 때는 **글자 하나도 바꾸지 말고** 화면 그대로 말한다.

- **소리 내어 (1~20번)**: 평소 대화하듯 보통 속도로. 프로그램이 내 입 모양을 익히는 "등록"에 쓰는 영상이다. 일부러 크게 입을 벌리거나 끊어 읽지 않는다.
- **소리 없이**: 목소리도 속삭임도 없이 **입 모양만**. 속도와 입 모양은 소리 낼 때와 똑같이. 목소리를 낼 수 없는 환자가 쓴다고 생각하고, 과장하지 않는다.

## 7. 목록에 없는 문장·짧은 말

- 화면에 나오는 문장을 그대로 **소리 없이** 말한다. 명령과 비슷하게 들리는 문장도 있지만 일부러 그렇게 만든 것이니 **화면 글자 그대로** 말한다.
- 이 문장들은 화면에만 나오고 이 안내에는 없다. 미리 연습하지 않아도 된다.

## 8. 말하지 않는 동작 10개

- 기침, 하품, 침 삼키기, 얼굴 찡그리기, 입술 핥기를 화면 지시대로 한다. **말은 하지 않는다.**
- **손으로 입을 가리지 않는다.** 기침·하품도 입이 보이게 한다(소리는 저장되지 않는다).
- 5초 안에 지시대로 한 번 하고, 남은 시간은 가만히 카메라를 본다.

## 9. 등받이에 기댄 자세 10개 (조정용만, 84~93번)

침대에서 등을 세우고 기대어 쉬는 환자가 침상 테이블 위 노트북으로 쓰는 장면을 흉내 낸다.

1. 83번까지 찍은 뒤 3분 쉬면서 자리를 바꾼다.
2. 의자 등받이를 뒤로 젖히거나, 침대에서 베개·쿠션을 받치고 **등을 비스듬히(약 30~45도) 기대어** 앉는다.
3. 노트북을 **배 높이 정도의 낮은 탁자**(침상 테이블, 좌탁 등) 위에 둔다. 무릎 위에는 두지 않는다(흔들린다).
4. 화면을 보며 노트북 화면 각도만 맞춰 **얼굴 전체와 입이 화면 안에** 들어오게 한다. 얼굴 앞쪽이 밝은지 다시 본다.
5. 회색 줄에 `등받이에 기대어 소리 없이`가 보이고 문장 위에 "기댄 자세 클립입니다" 안내가 뜨면 그대로 찍는다. 방법은 4장과 같다(소리 없이).

## 10. 쉬는 때

- 20클립마다 1분 쉰다. 쉬는 동안 의자와 카메라는 움직이지 않는다(9장의 자세 바꾸기만 예외).
- 물은 쉬는 시간에만 마신다.

## 11. 다 찍었으면

1. 화면에 "촬영이 끝났습니다"가 나온다.
2. **폴더에 저장한 경우**: 저장 폴더의 파일 수를 본다. 조정용은 **186개**(영상 93 + 기록 93), 평가용은 **206개**(영상 103 + 기록 103)여야 한다. 모자라면 같은 가명 ID·같은 촬영 묶음·같은 폴더로 프로그램을 다시 열고 **이어 찍기**로 빠진 클립을 찍는다.
3. 5초에 잘린 클립, 다시 찍은 클립, 그 밖에 이상했던 클립은 `가명ID_메모.txt`(예: `P01_메모.txt`)에 적어 저장 폴더 안에 둔다. 예: `silent W07 1회차 - 5초에 잘림`, `silent W12 2회차 - 글자 바꿔 말해서 다시 찍음`, `none X03 - 하품이 잘 안 나옴`.
4. 저장 폴더를 오른쪽 클릭 → 압축(ZIP)한다. 이름은 가명 ID로 시작하게 한다. 예: `P01_병실명령.zip`
   화면에 모아 둔 경우(노란 상자)에는 "내려받기 (zip)"로 받은 zip 중 **가장 마지막에 받은 것 하나**를 보낸다. 이름은 `P01_ward_tune_웹캠촬영.zip`(조정용) 또는 `P02_ward_eval_웹캠촬영.zip`(평가용)처럼 촬영 묶음이 들어가 있어 예전 문장 촬영 zip(`P01_웹캠촬영.zip`)과 섞이지 않는다. 메모는 zip과 함께 따로 보낸다.
5. 0장의 방법으로 팀장에게 보낸다. **단톡방, 공개 링크에는 올리지 않는다.**
6. 팀장이 잘 받았다고 하면 내 PC의 저장 폴더와 압축 파일을 지운다.

## 12. 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 녹화가 8초까지 가고 스페이스바로 멈춘다 | 촬영 묶음을 문장 촬영으로 골랐다. 찍은 클립이 있으면 팀장에게 알리고, 새 빈 폴더에서 병실 명령 묶음으로 처음부터 찍는다. |
| "촬영 묶음이 서로 다른 클립이 섞여 있습니다" 또는 "…클립이 있는데 지금 고른 촬영 묶음은 …입니다" | 예전 촬영 폴더를 골랐거나 묶음을 잘못 골랐다. 1장의 새 빈 폴더와 0장의 내 묶음인지 확인한다. |
| 말이 끝나기 전에 녹화가 멈췄다 | **다시 찍지 않는다.** 그대로 두고 메모에 적은 뒤 다음으로 넘어간다(4장). |
| 준비하기 전에 다음 클립 녹화가 시작됐다 | 멈출 수 없으니 5초 동안 가만히 카메라를 본다. 저장되면 "이전 (다시 찍기)"로 그 순번에 돌아가 다시 찍고 메모에 적는다. |
| 카메라가 안 열린다 | 주소창 왼쪽 아이콘 → 카메라 허용. 줌·카톡 영상통화 등 카메라를 쓰는 프로그램을 끈다. |
| 중간에 창을 닫았거나 새로고침했다 | `웹캠촬영.html`을 다시 열고 같은 가명 ID → 같은 촬영 묶음 → 같은 폴더 → 카메라 열기 → **이어 찍기** 버튼. |
| 잘못 말했는데 이미 다음으로 넘어갔다 | "이전 (다시 찍기)"를 눌러 돌아가 다시 찍는다. 지나간 순번은 화면 아래 "순번으로 가기"로 간다. |
| 촬영 묶음 선택이 회색으로 잠겼다 | 정상이다. 한 클립이라도 저장했거나 폴더에 이미 클립이 있으면 잠긴다. 묶음을 잘못 골랐으면 팀장에게 알리고 새 빈 폴더로 처음부터 찍는다. |
| 그 밖에 막히면 | 화면을 캡처해서 팀장에게 보낸다. |
