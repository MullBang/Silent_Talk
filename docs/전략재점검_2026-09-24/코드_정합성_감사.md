## 1. 판정

**웹캠 입술 영상 → 한국어 텍스트라는 입력·출력 방향은 최종목표에 부합한다. 다만 현재는 구현과 진단 기반을 갖춘 연구용 베이스라인이며, 처음 보는 사람의 자유로운 문장을 읽는 프로그램의 성능은 확보되지 않았다.** 같은 소수 화자·같은 녹화의 문장을 늘리거나 반복 학습하는 방식만 계속하는 것은 권하지 않는다. 기존 전처리·검증·웹캠 통신 기반은 보존하고, 검증된 시각 사전학습 모델의 한국어 전이 가능성, 화자·촬영 조건 다양성, 학습/웹캠 전처리 차이를 함께 다루는 방향으로 계획을 재정렬할 필요가 있다.

이는 1~17단계가 무의미했다는 뜻이 아니다. 잘못된 한글 표현·입술 좌표·시간축·CTC 길이·웹캠 전송과 평가 누수를 방지하는 기반을 만들었고, 소수 문장 암기와 미학습 문장 인식이 다르다는 것을 실제 결과로 확인했다. 반면 단계 수가 늘어났다는 사실을 인식 성능의 지속적인 향상으로 해석해서는 안 된다.

## 6. 재개 전 결정할 실행 순서

아래는 제안이며 이번 요청에서 실행한 작업이 아니다.

1. **데이터 복구와 저장 경로 확정:** 정상 원본을 독립 로컬 작업 디스크에서 검증하고, 학습에는 필요한 입술 ROI·라벨만 사용한다. 손상본을 짧게 재생되도록 고치는 것과 완전한 훈련 데이터를 복구하는 것을 구분한다.
2. **목표와 평가 계약 확정:** 최종목표는 소리 없이 새 화자의 한국어 문장을 추정하는 것. 1차 검증은 발화 종료 후 출력으로 두고, 자유문장·제한문장 데모·실시간 지연 목표를 나누어 정의한다.
3. **사전학습 후보 적합성 확인:** 논문 이름만 선택하지 말고 공식 코드·공개 checkpoint·입력 규격·한국어 전이 방법·GPU 메모리·사용 조건을 확인한다. 현재 compact는 비교 기준으로 보존한다.
4. **작고 유효한 비교 자료 구성:** 같은 화자의 문장 수만 늘리기보다 다른 화자·다른 녹화·성별·촬영 조건을 확보한다. 용량 GB가 아니라 화자 수·녹화 수·중복 없는 발화 시간·길이 분포로 계획한다. 정확한 목표 규모는 모델 후보와 사용 가능한 정상 데이터가 확인된 뒤 정한다.
5. **전처리 대조와 모델 비교:** 라벨 ROI 대 서비스 검출 ROI 차이를 먼저 기록한다. 새로운 전처리 계약을 버전으로 만들고, 사전학습 기반 후보와 기존 기준선을 동일한 개발 평가 세트로 비교한다. CTC 모델이 아닌 후보라면 현재 CTC 제한을 무조건 이식하지 않는다.
6. **실제 웹캠 평가와 서비스 연결:** 저장 영상에서의 미학습 문장 성능이 확인되면 실제 웹캠으로 확장한다. 얼굴 검출 성공만으로 인식 성공을 선언하지 않는다. accuracy·latency·실패 처리 기준을 통과한 가중치만 배포 명세에 연결한다.

판단을 바꾸기 위해 가장 먼저 필요한 증거는 **현재와 다른 정상 화자·촬영 자료에서, 시각 사전학습을 활용한 후보가 기존 compact보다 일관되게 낮은 미학습 오류를 내는지**, 그리고 **같은 영상의 서비스 ROI에서도 그 효과가 유지되는지**다. 현재 실험을 그대로 길게 이어가는 것보다 이 두 질문을 먼저 해결하는 편이 최종목표에 직접 연결된다.
