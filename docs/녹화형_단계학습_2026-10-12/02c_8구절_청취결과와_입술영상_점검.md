# 녹화형 2단계 후속 — 8구절 청취 결과와 입술 영상 점검

작성일: 2026-10-13. 실행 폴더: `experiments/offline_boundary_review_step02c_20261013/`.

**추천한 8화자·8구절의 음성 구간 확인을 마쳤다. 기존 자동 후보에서 끝부분 잘림이 반복돼 일부 끝 시각 또는 구절 구성을 변경했고, 새 음성도 사용자에게 다시 확인받았다. 입술 영상의 표본 품질 검사는 통과했지만, 발음별 시각 경계와 부모 문장 전체의 검수는 아직 미완료다. 새 학습은 실행하지 않았다.**

## 주요 결과

처음 추천한 8개 자동 구절 중 사용자는4개가 온전히 들리고,4개는 마지막 부분이 잘린다고 보고했다. 이는 의도적으로 고른 작은 검수 사례의 결과이며 전체 데이터의 오류율이 아니다. CTC 최소 길이를 만족했던 후보에서도 발음이 빠졌다. **프레임 수가 충분하다는 조건만으로 학습 구간의 정답이 정확해지는 것은 아니다.**

자동 정렬의 토큰 발생 구간은 발음 전체를 포괄하는 경계로 그대로 쓸 수 없었다. 이번 결과는 그러한 우려를 실제 청취에서 확인한 근거다. 특정한 고정 길이를 모든 구절에 더하면 해결된다고 판단하지 않는다.

## 잘림 보고와 변경을 어떻게 반영했는가

④의 기존 “야근을 많이 해서”는 ‘해’까지만 들리고 ‘서’가 빠진다고 사용자가 답했다. 끝을0.08초 늘려도 여전히 잘린다는 답을 받았다. 이 두 후보를 보류 기록으로 남기고, 다음 단어를 함께 포함하는 **“많이 해서 잠이 부족해”**로 시작·끝·정답을 모두 바꿨다. 사용자가 이 새 구절은 온전히 들린다고 확인했다. 기존의3어절 구간을 그대로 복구했다고 기록하지 않는다.

⑦은 마지막 ‘어’, ⑧은 마지막 ‘혀’가 잘렸다는 사용자 답변을 받았다. 정답은 유지하고 원래 부모 문장 음성의 끝까지 포함한 후보를 별도로 만들었고, 둘 다 온전히 들린다는 답변을 받았다. 확장 폭은⑦2,648샘플(165.5ms),⑧2,499샘플(156.1875ms)다. 이는 사용해 본 범위 차이이며 실제 정답 경계의 오차 측정값이 아니다.

전체 명세에는 원래410후보와 이전 C312 수정1개, 이번 추가4개를 합쳐415개가 있다. 추가4개에는 실패한 C004+80ms도 포함된다. 따라서415개를 독립 학습 예시나 성공 예시로 세지 않는다.

이번3개 답변 파일은 실제 질문ID·문장ID·구절·재생 WAV 해시·정확한16kHz 샘플 범위를 연결한다. ④에 관한 자유 형식 답변과 뒤이어 도착한 같은 질문의 답변은 한 판단으로 처리했다. 응답 범위는 해당 구절의 음성에만 적용하며, 사용자가 보지 않은 영상이나 듣지 않은 전체 문장의 승인으로 확대하지 않았다.

## 입술 영상 표본 검사

기존 검수용 전체 화면/입술 MP4를 디코딩해 시작·중간·끝 주변 프레임을 관찰했다. 최신8구절에 대해 **입술 영역89개와 전체 화면24개 표본**을 확인했다. 이전 후보와 실패한 수정안까지 포함한24개 그림·166개 패널도 별도로 보존했다.

검토한 표본에서 입술의 명백한 공간 잘림, 가림, 심한 흐림은 발견하지 못했다. 그러나 입 모양이 열려 있거나 다물렸다는 정지 화면 관찰만으로 어떤 음절이 끝났는지 판단할 수 없다. 예를 들어 새 C293 끝부분은 더 다문 모습이고 C004·C297 끝 주변에는 열린 모습이 있지만, 이를 발음 경계의 성공/실패로 해석하지 않았다.

그림은 기존25fps 검수용 재압축 영상에서 추출했다. 각 표본의 요청 시각, 검수 프레임, 기존 원본 프레임 추적 정보를 연결했으나 원본 TAR에서 픽셀을 새로 읽어 검증한 것은 아니다. 원천·그림71개 해시와166개 픽셀 패널 대조가 통과했다. 이 기술 관찰은 **에이전트의 시각 표본 검사**이며 사람의 시각 경계 승인을 생성하지 않는다.

최신 시각 인계는 `visual_review/latest_eight_visual_manifest.json`, 관찰 보고서는 `visual_review/visual_review_report_r2.txt`다. 최초8개 그림의④·⑦·⑧은 변경 전 후보이므로 최신 파일 연결을 따라야 한다.

## 재현성과 검수 화면

독립 감사에서 기존2b단계 동결 파일41개와 출처 해시71개를 확인했다. 전체415후보의 연속 어절·정수 샘플 시각·유리수 half-even 프레임 계산·69자모 CTC 최소 길이를 별도로 재계산했다. 이전/이번의 실제 답변13건과 해당 WAV13개도 원본 문맥 PCM과 정확히 일치했다. 감사기는 생산 코드를 가져오지 않았다.
