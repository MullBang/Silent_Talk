# 녹화형 계획 1단계 — 보유 자료의 어절 분포와 경계 준비 상태

작성일: 2026-10-12. 상태: **메타데이터 조사 완료, 어절 정렬·학습은 미실행**.

## 조사 결론

기존 자료만으로 짧은 구간 학습을 위한 첫 경계 검수는 시작할 수 있다. 보수적으로 추린 **293문장·8화자·35녹화**에서 어절은 2,531회 등장하며 서로 다른 표면형은 1,599종이다. 그중 1,276종(약 79.8%)은 한 번만 등장하므로 모든 어절을 독립 단어 학습 대상으로 삼기는 어렵다. 여러 화자·녹화에 반복되는 어절과 자연스러운 연속 구절부터 준비한다.

**2,531회는 텍스트의 어절 등장 횟수이며, 확보된 단어 영상 수가 아니다.** 이번에 확인된 단어 경계와 생성한 단어 클립은 0개다. 16문장을 경계 정렬 파일럿 후보로 정했으며, 사람의 전체 전사 승인이나 학습 가능 상태로 승격하지 않았다.

## 조사 범위와 제외

| 처리 | 남은 수 |
|---|---:|
| 기존441 + 잠정 신규69 후보 | 510문장 |
| 이전 15단계의 old8 범위·기존 probe 녹화 및 금지 전사 제외를 계승 | 368문장 |
| 직전 dev16이 속한 8녹화 전체와 일치하는 74문장 제외 | 294문장 |
| 다른 녹화지만 dev16과 전체 전사가 같은 1문장 추가 제외 | **293문장** |

마지막 제외 항목은 `lip_J_1_F_03_C312_A_007_013`이다. 녹화 동일성은 stem·영상 SHA·라벨 SHA를 확인하며, 전체 전사 중복은 NFC·공백 제거 기준이다. 어절 집계에는 공백을 보존한 `text`를 사용했다. 이전 `normalized_target`은 공백 제거용 필드여서 어절 집계에 쓰지 않았다.

전체 632개 연결 레코드(학습 후보510 + 개발95 + 보류27)의 원본 JSON 레코드 SHA와 화자·녹화·분할·프레임 수를 확인했다. 기존 후보를 사람 승인 자료로 간주하지 않는다. 잠정 신규69는 이번 작은 파일럿 범위에 넣지 않았으며 미응답 검수2개도 그대로다.

현재293과 기존 개발71의 동일 stem 녹화 공유는 0개다. 다만 이 수치로 다중 카메라·복제본까지 포함한 모든 녹화 분리를 보장하지 않는다. 앞으로 학습/개발을 나눌 때 부모 녹화를 묶는 별도 검사가 필요하다. 현재 범위는 과거 학습 후보이므로 최종 미접촉 시험 자료가 아니다.

## 어절 분포

여기서 어절은 `text.split()`으로 얻는 공백 구분 표면형이다. 형태소 분석이나 사전 기본형 복원은 하지 않았다. 예를 들어 ‘같아’와 ‘같아서’는 서로 다른 항목이다.

| 지표 | 직전 학습72 | 이번 조사293 |
|---|---:|---:|
| 어절 등장 횟수 | 611 | 2,531 |
| 서로 다른 표면형 | 477 | 1,599 |
| 한 번만 등장한 표면형 | 414 | 1,276 |
| 2명 이상에게 등장 | 51종 | 250종 |
| 3명 이상에게 등장 | 22종 | 103종 |
| 4명 이상에게 등장 | 9종 | 49종 |
| 5명 이상에게 등장 | 3종 | 29종 |

293문장의 기존 입력은 총32,607프레임, 25fps 기준 약21.74분이다. 여러 파일을 더 읽는 것과 새로운 화자·발음·문맥을 충분히 확보하는 것은 구분해야 한다.

경계 검수 우선 후보는 **8회 이상·4화자 이상·4녹화 이상·한글 2음절 이상**이라는 간단한 빈도 기준으로 정했다. 다음 12종은 고정 인식 어휘나 학습 성공이 보장된 목록이 아니라 검수 후보 목록이다.

각 어절의 전체 문장 ID와 화자 목록은 `eojeol_frequencies.json` 및 `review_shortlist.json`에 있다. 같은 문장에서 같은 어절이 두 번 나오면 등장 횟수는 2, 문장 수는 1로 계산했다.

## 경계 검수 후보 16문장

8명 각각 서로 다른 2녹화에서 골랐다. 기존 입력 길이50~188프레임 범위, 숫자·영문·대안 표기 없는 전사, 위 어절을 하나 이상 포함하는 후보 안에서 서로 다른 우선 어절을 많이 포함한 문장을 먼저, 그다음 짧은 문장과 ID 순으로 정했다. 이는 경계 준비를 위한 선택 규칙이며 모델의 손실이나 예측 결과는 사용하지 않았다.

## 다음 단계 전에 해결할 사항

원라벨 표본의 `Sentence_info`에는 문장 시작·끝만 있고 어절·음절 시각은 없다. 이전 Whisper 단어시각은 120문장 모두 첫 단어가0초였으며 자동 선택으로86문장의 첫 단어를 제외하는 문제가 있어 그대로 재사용하지 않는다. [이전 시간 진단](../실행계획_2026-10-07/07_전사정규화_및_문맥검수.md)

2단계는 실제 전사와 경계를 확인하고 한국어 강제 정렬 후보를 검수하는 작업이다. 자모 CTC 최소 프레임이 모자라면 주변 어절과 전사까지 함께 묶거나 제외한다. 음성은 이 자료 준비 과정에서만 사용하며 최종 인식은 영상만 입력한다.

현재 PATH와 점검한 `.venv-audio-audit`, `.venv-gpu`에서는 MFA/WhisperX를 찾지 못했다. PC 전체의 설치 유무를 단정하는 검사는 아니며, 별도 정렬 환경과 모델 준비가 필요할 수 있다.

## 수행한 검사와 보존 범위

- 분석 입력 JSON 5개의 바이트 해시를 기록했고 실행 전후 동일함을 확인했다. 이전15단계 계획과 연결된 handoff/old/new 계획의 고정 해시도 확인했다.
- 전체632개 논리 레코드 연결과293개 D: 영상/라벨의 메타데이터 SHA 연결을 점검했다.
- D:의 TL1/TL10/TS1/TS10 TAR 4개는 현재 존재하고 과거 기록의 크기·수정 시각과 같았다. **이번에는 TAR 내용의 전체 무결성 검사를 반복하지 않았다.** 실제 구간을 사용할 때 해당 멤버를 검증한다.
- 독립 검산이 통과했다. 생산 함수를 가져오거나 실행하지 않고 원본 JSON에서 제외 목록·1,599종 전체 어절 빈도·16문장 선택·승인 상태를 다시 계산해 대조했다. 근거와 한계는 아래 감사 파일에 남겼다.
- 이번 실행은 JSON과 파일 속성만 읽었다. 원본 영상·음성 디코딩, NPZ/가중치 텐서 읽기, 신규 추론·학습·다운로드·서비스 교체는 하지 않았다. 원본 라벨과 기존 동결 코드를 보존했다.
