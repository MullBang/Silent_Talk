# 8구절 검수 확인과 원본 추출 준비

작성일: 2026-10-13. 이 문서는 앞선 2d의 ‘시각 답변 대기’ 상태 이후에 받은 실제 사용자 답변을 반영한다.

**현재 추천 8구절에 대해 구절 음성, 부모 전체 문장의 전사·음성 경계, 검수 영상의 뚜렷한 잘림 여부를 확인했다.** 사용자는 영상 비교 질문에 “8개 모두 뚜렷한 잘림은 보이지 않음”이라고 답했다. 하나의 통합 답변을 질문에 명시된 최신 8개 구절에 연결했다. 정확한 음절 시작·끝을 측정했다는 뜻은 아니다.

최신 구절 범위와 정답을 그대로 유지했다. 영상 비교에 사용한 앞뒤 0.20초를 학습 범위에 자동으로 추가하지 않았다. 이전에 잘렸던 후보와 실패한 수정안도 보존했다. ③·⑦은 다른 화자지만 구절과 전체 문장 전사가 같으므로 ‘새 문장 인식’ 평가의 양쪽 집합에 나눠 넣으면 안 된다.

## 준비한 원본 추출 명세

`experiments/offline_boundary_finalize_step02d_20261013/results/extraction_plan.json`에 구절별 원본 TAR 멤버·출처 해시, 원본 WAV/영상 시각, 25fps 목표 시각, 예상 원본 프레임 인덱스, 정답 토큰과 CTC 길이를 연결했다. 음성 시각에는 기존에 확인한 WAV→영상 보정값을 한 번만 적용했다. 반올림된 라벨 FPS=30을 쓰지 않았다.

현재 ‘구절 시작부터 25fps·정수 샘플 길이의 half-even 반올림’ 규약으로 예상되는 수량은 **233프레임**이다. RGB 96×96 uint8 픽셀만으로는 압축 전 약 **6.14MiB**이며, 컨테이너·메타데이터·임시 원본 공간은 별도다. 실제 원본 픽셀이나 학습 캐시를 이번에 생성한 것은 아니다.

**원본 추출 후 첫·마지막 프레임 대조가 남아 있다.** 새로 구절 시작부터 프레임을 뽑으면 기존 문맥 검수 영상과 샘플링 시작점이 다르다. 현재 규약의 예상 마지막 원본 프레임 시각은 ①에서 구절 끝보다 약74.17ms, ⑦에서 약55.36ms 앞이다. 검수 영상에서의 ‘뚜렷한 잘림 없음’을 아직 추출하지 않은 새 픽셀에 대한 확인으로 확대하지 않았다.

추출 시 실제 PTS·프레임 수·선택 인덱스·입술 좌표·첫끝 프레임을 비교해야 한다. 필요한 움직임이 빠진다면 프레임 반복이나 문맥 추가로 조용히 보정하지 않고, 별도 추출 규약 또는 구간 수정안으로 기록한다. 따라서233은 현재 규약의 계획 수량이며 경계 대조까지 마친 최종 학습 수량은 아니다.
