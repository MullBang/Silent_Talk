# 녹화형 립리딩과 짧은 구간부터의 학습 계획

작성일: 2026-10-12. 이전 `실행계획_2026-10-07`의 16단계까지는 과거 실험 기록으로 보존한다. 앞으로의 단계 번호는 이 문서의 **녹화형 계획 1~8단계**를 뜻한다.

## 목표와 현재 출발점

**웹캠으로 30초 미만의 영상을 녹화한 뒤, 소리를 인식 입력으로 사용하지 않고 입술의 움직임을 분석해 한국어 텍스트를 출력한다.** 먼저 짧은 발화로 검증하고, 이후 여러 문장이 들어 있는 녹화로 확장한다. 제한된 단어 목록에서 답을 고르는 기능은 중간 진단일 뿐 최종 문장 인식의 완성이 아니다.

현재 학습은 이미 원본 약 5분 영상을 문장별로 나누어 수행하고 있다. 직전 확대군 72문장의 입력은 각각 1.32~7.52초, 평균 약 4.16초다. 이번 변경의 핵심은 긴 원본을 처음으로 자르는 것이 아니라 **문장보다 짧은, 경계가 확인된 어절·구절을 추가하고 학습 순서를 비교하는 것**이다.

직전 실험에서는 학습 문장을 모두 맞혔지만, 검증 16문장은 모두 틀렸다. 문장 다양성 확대로 검증 CER는 평균 105.57%에서 86.46%로 낮아졌으나 실용적인 인식 성능은 아니다. 길이 하나를 원인으로 단정하지 않고 경계 품질, 학습량, 문장 다양성, 새로운 발화에 대한 성능을 함께 확인한다. [직전 결과](../실행계획_2026-10-07/16_문장다양성_비교학습.md)

## 2단계에서 바로 할 일

1. 1단계의 16문장 후보와 D: 원본 연결을 재확인한다. 원본 전체를 풀지 않고 필요한 녹화와 구간만 임시로 읽는다. 기존 G: 경로는 과거 식별 정보로만 취급한다.
2. 음성, 전체 문장 전사, 시작·끝 경계를 확인한다. 자동 전사와 다르거나 재시작·추가 발화가 모호하면 사용자에게 해당 부분의 청취 판단을 요청한다. 자동 일치를 사람 승인으로 기록하지 않는다.
3. 별도 환경에서 한국어 강제 정렬 도구와 모델을 점검·준비한다. 확인한 실행 경로와 가상환경에는 MFA/WhisperX가 아직 발견되지 않았으므로 설치·모델 준비가 필요할 수 있다. 사용할 도구는 실제 호환성과 파일럿 결과로 결정한다.
4. 전사가 맞는 구간에만 정렬 후보를 만든다. 후보 어절의 앞뒤 문맥과 입 움직임을 확인하고, 원래 음성 시간과 보정된 영상 시간을 모두 보존한다.
5. 검수 통과한 어절과 자연스러운 2~4어절 구절의 명세를 만든다. 이 단계에서는 대규모 학습을 하지 않는다.

현재 후보는 8명×서로 다른 2녹화, 총 16문장이다. 합계 약 60.32초이며 문장별 입력은 2.56~7.12초다. **이는 기존 25fps 입력의 프레임 수에 따른 명목 길이이며 원본을 이번에 재생·검증한 결과가 아니다.** 후보를 실제로 들었을 때 부적절하면 교체 이유를 남겨 같은 제외 규칙 안에서 대체한다.

## 학습 설계의 기준

- **학습 단위와 출력 단위를 구분한다.** 영상을 어절·구절로 나누더라도 출력은 기존 한글 위치별 자모 69토큰 CTC를 우선 유지한다. 매 어절을 독립 클래스 하나로만 예측하는 모델로 최종 목표를 대체하지 않는다.
- **음절별 강제 절단부터 시작하지 않는다.** 입 모양은 주변 발음과 이어져 변하므로 음성 경계가 시각 경계와 정확히 일치한다고 가정하지 않는다. 어절 주변 문맥을 검토하고, 필요하면 자연스러운 연속 구절로 묶는다.
- **짧은 구간도 CTC 길이를 검사한다.** `T >= 토큰 수 + 인접 동일 토큰 쌍 수`를 만족해야 한다. 부족하면 인접 어절과 정답을 함께 확장하거나 제외한다. 균등 시간 나누기·정답 삭제·과도한 반복 패딩으로 해결하지 않는다.
- **자료 준비용 음성과 인식용 입력을 분리한다.** 원자료의 음성은 전사와 시간 경계 확인에 사용할 수 있다. 학습하는 시각 인식 모델과 최종 프로그램에는 음성을 넣지 않는다. 기존 시각 교사 특징을 쓸 경우 두 비교군의 사용 규약을 맞춘다.
- **새 비교군은 같은 출발 조건에서 만든다.** 기존 모델의 역사적 수치와 새 데이터 수치를 직접 비교하지 않는다. 신규 초기화·부모 자료·전처리·평가군·교사 사용·최적화 규칙을 사전에 고정한다. 단계 학습만 유리하게 총 반복을 늘리지 않는다.
- **학습 예산을 여러 방식으로 기록한다.** 업데이트 수, 실제 처리 프레임 수, 각 부모 문장/자식 구간 노출 수, 학습 시간을 모두 보고한다. 짧은 구간의 길이가 다르면 같은 업데이트 수만으로 같은 계산량이라고 주장하지 않는다. 4단계에서 주 비교 예산과 차이를 확정한다.
- **암기와 새 발화 인식을 따로 평가한다.** 같은 어절의 다른 화자·녹화, 학습하지 않은 어절 조합·문장, 다른 화자의 문장을 구분한다. 정상/정지/순서 섞기 비교도 유지한다. 틀린 문장을 언어 모델로 자연스럽게 바꾼 것과 실제 시각 인식 개선을 구별한다.

짧은 구간이 효과적인지 판단할 연구 기준은 4단계에서 고정한다. 예를 들어 두 초기값에서 내부 미학습 CER가 모두 낮아지고 평균 5%p 이상 개선되면 추가 연구 근거로 삼을 수 있지만, **그 자체가 사용 가능한 프로그램의 성공 기준은 아니다.** 최종 사용 조건과 정확도·지연 목표는 웹캠 평가 전에 별도로 명시한다.

## 데이터와 평가 보호

현재 293문장은 과거 학습 후보에서 고른 **메타데이터 조사 범위**다. 전체 사람이 검수한 단어 자료나 새 학습/개발 분할이 아니다. 과거 개발95·보류27의 ID/전체 전사 제외를 계승하고, probe14 및 직전 dev16은 녹화 stem·영상 SHA·라벨 SHA와 전체 전사로 보호했다. 이 293개와 기존 개발71 사이의 동일 stem 녹화 공유는 이번 집계에서 0개였지만, 다른 카메라 시점과 원본 복제본의 묶음까지 검증한 것은 아니다.

3단계에서는 **단어를 자르기 전에** 부모 녹화의 역할을 확정한다. 동일 녹화의 다른 문장·중첩 문맥·다른 카메라 시점·같은 사본이 분할을 넘지 않게 원본 기록을 함께 묶는다. 개발군의 문맥 프레임이 학습 구간에 섞여도 누수이므로 검수한다. 공통 어절이 학습·개발에 등장하는 것은 어절 인식 평가의 설계일 수 있지만, 동일 문장·원본 구간이 넘어가는 것과 구별한다.

이전 결과를 보며 골랐던 자료는 새로 나눠도 미접촉 최종시험이 되지 않는다. 공개 교사 모델의 사전학습 중복 여부도 미확인이다. 최종 평가는 별도로 고정한 자료나 동의를 받아 이후 촬영한 웹캠 발화로 마련한다. 사용자의 미응답 검수 항목과 보류 상태는 유지한다.

## 저장 공간과 추가 자료

현재 단계와 16문장 파일럿은 기존 D: TAR와 메타데이터로 시작한다. **추가 AIHub 원본 다운로드는 현재 필요하지 않다.** TAR는 원본 보관용으로 유지하고, 필요한 구간의 ROI와 출처 명세만 별도 로컬 캐시로 만든다. 매 epoch마다 대형 TAR 전체를 순회하거나 Google Drive 재다운로드·재업로드를 반복하는 방식은 피한다. 단계별 임시 공간과 파생 캐시의 실제 크기를 먼저 재고 확대한다.

특정 어절의 여러 화자 예시가 부족하거나 새 화자 검증 자료가 필요해질 때, 필요한 화자·녹화·구간 수와 예상 용량을 먼저 사용자에게 알린다. 정렬 도구/모델 파일 다운로드와 AIHub 학습 원본 추가 다운로드는 구분해서 설명한다.

## 구현에서 유지할 조건과 변경이 필요한 부분

25fps 시각 기반 샘플링, 96×96 ROI, margin 0.20, 같은 정규화, last-frame 배치 패딩, 가변 T, 69토큰 사전은 새 실험에서도 우선 유지한다. 원본 라벨·기존 가중치·동결된 실험 코드는 덮어쓰지 않는다.

현 웹캠의 스트리밍 흐름과 3초 세그먼트 처리는 새 녹화형 목표에 맞는지 별도로 수정·검증해야 한다. 30초 녹화를 무조건 하나의 거대한 입력으로 넣거나 3초마다 단어 중간에서 잘라 단순 연결하지 않는다. 영상만으로 구간을 찾는 방법, 문맥 중첩과 중복 제거, 무발화·얼굴 미검출 처리를 6~7단계에서 평가한다. 브라우저가 만드는 실제 녹화 형식과 서버 업로드 허용 형식도 함께 맞춘다. 자동 종료는 컨테이너의 실제 길이가 30초 미만이 되도록 여유를 두고 서버에서도 검사한다.

## 계획의 연구 근거

- [Chung 등, Lip Reading Sentences in the Wild, CVPR 2017](https://www.robots.ox.ac.uk/~vgg/publications/2017/Chung17/chung17.pdf): 단어에서 더 긴 시퀀스로 학습 난도를 높이는 curriculum 사례. 해당 영어 자료의 개선 폭을 우리 한국어 소규모 자료의 보장값으로 사용하지 않는다.
- [Afouras 등, Deep Lip Reading, Interspeech 2018](https://www.isca-archive.org/interspeech_2018/afouras18b_interspeech.pdf): 시각 앞단의 단어 학습과 짧은 연속 구간부터의 학습 사례. 필요한 단어 경계 준비가 전제다.
- [Graves 등, CTC, ICML 2006](https://www.cs.toronto.edu/~graves/icml_2006.pdf): CTC 자체는 프레임별 정답 정렬을 요구하지 않는다. 이번 경계 작업은 짧은 학습 예시를 만들기 위한 것이다.
- [Korean MFA acoustic model](https://mfa-models.readthedocs.io/en/latest/acoustic/Korean/Korean%20MFA%20acoustic%20model%20v3_0_0.html): 한국어 강제 정렬의 후보 도구. 실제 잡음·전사·도메인에 대한 적합성은 파일럿으로 확인한다.

상세한 1단계 수량과 출처는 [1단계 결과](01_어절분포_조사.md)를 따른다.
