# 녹화형 5c — 구절 전용 학습과 재현 검증

작성일: 2026-10-18. 상태: 고정된 구절 전용 학습·평가 완료. 문장 확대와 서비스 교체는 하지 않았다.

**같은 구절을 계속 학습하자 두 모델 모두 마지막에는 학습 구절 12개를 전부 맞혔다.** 현재 모델이 이 작은 학습집합을 재현할 수 있다는 점은 확인됐다. 다만 초기값 43은 1,260회에서 한 글자를 틀렸으므로, 두 초기값 모두 마지막 두 평가에서 완벽해야 한다는 사전 기준은 미충족이다. 정지 영상에서도 각각 8개를 맞혀, 이 결과를 새로운 발화의 입 움직임을 이해한 증거로 해석할 수는 없다.

## 무엇을 확인하려 했나

이전 5단계는 구절 420회 뒤 전체 문장으로 전환했다. 전환 당시 학습 구절 완전 일치는 초기값 42가 1/12, 초기값 43이 0/12였다. 이번에는 **같은 구절을 계속 학습하면 어디까지 재현할 수 있는지**를 확인했다. 새 문장 성능이나 구절 학습의 일반적인 우월성을 측정하는 실험은 아니다.

| 항목 | 실제 실행 |
|---|---|
| 자료 | 기존 학습 구절 12클립·고유 전사 11종·기존 화자 8명·원본 캐시 481프레임 |
| 모델 | 새 초기화 compact 3D-CNN(32/64/96) → 256차원 투영 → 2층 양방향 LSTM(방향별 256) → 69토큰 CTC |
| 파라미터 | 3,287,781개; 교사·사전학습 가중치 사용 없음 |
| 입력 | 25fps·96×96 RGB 입술 영상, ImageNet 정규화, 배치 2, 실제 길이 처리 |
| 출력 | 한글 자모·공백·blank 포함 69토큰; 구절 분류기가 아닌 토큰열 예측 |
| 초기값·반복 | 42·43 각각 1,680업데이트; 구절마다 280회 노출 |
| 학습률 | 1–840회 0.001, 841–1050회 0.0003, 이후 0.0001 |
| 평가 | 420/840/1260/1680회 정상 영상; 마지막에 정지·섞기 추가 |
| 사용하지 않은 입력 | 개발 구절·전체 문장의 모델 입력, 음성, 새 원본 다운로드 |

첫 420회는 이전 B 실험과 초기 상태·모델·Adam·난수 상태·학습 순서·손실·기울기가 완전히 일치했다. 해당 정상 평가 확률 24개도 배열 단위로 같았다. 따라서 초반 실행이 달라져서 생긴 개선은 아니다. 다만 420회 이후에는 학습 대상과 노출량이 달라졌으므로, 이전 결과와의 차이를 순수한 학습 순서 효과라고 부르지 않는다.

## 학습 구절의 결과

CER는 NFC 정규화한 문자 오류율이다. 내부 공백과 잘못 조합된 자모의 오류 문자를 보존하며, 낮을수록 좋다. 아래 각 행은 같은 12개 구절의 반복 관측이고, 새로운 12개 자료를 매번 평가한 것이 아니다.

| 업데이트 | 초기값 42 완전 일치 | 초기값 42 CER | 초기값 43 완전 일치 | 초기값 43 CER |
|---|---:|---:|---:|---:|
| 420 | 1/12 | 59.09% | 0/12 | 60.61% |
| 840 | 11/12 | 0.76% | 7/12 | 10.61% |
| 1,260 | 12/12 | 0.00% | 11/12 | 0.76% |
| 1,680 | **12/12** | **0.00%** | **12/12** | **0.00%** |

1,260회에서 남았던 초기값 43의 오답은 C032_A_002_030 구절이다.

- 정답: **“너무 많이 먹고 와”**
- 예측: **“너무 마이 먹고 와”**
- 전체 132문자 중 문자 편집 오류 1개였으며, 1,680회에서는 정확히 출력했다.

이 한 오답의 저장 확률을 분석하면, 정답 문구의 전체 CTC 확률이 실제 greedy 출력 문구보다 높았다. 정답과 greedy의 음의 로그 확률 차이는 약 −1.29639다. 프레임마다 최고 토큰을 택하는 greedy 선택의 한계가 이 사례에 관여했을 가능성이 있다. 새 탐색 디코더를 실행한 결과는 아니며, 이전 단계의 모든 오류가 같은 이유였다는 뜻도 아니다. 원래 greedy 평가와 기준 판정은 유지한다.

**사전 통과 기준은 바꾸지 않았다.** 초기값별로 1,260회와 1,680회 모두 12/12·CER 0이어야 하므로 초기값 42만 통과했고, 두 초기값을 함께 판정한 기준은 미충족이다. 이는 엄격하게 정한 작은 학습집합 재현 기준이며, 모델이 전혀 학습하지 못했다는 뜻은 아니다. 반대로 마지막 12/12만 골라 일반화 성공으로 보고하지도 않는다. 정해진 1,680회에서 종료했고 추가 반복은 하지 않았다.

## 정지·섞기 대조가 보여 준 한계

정지 조건은 각 구절의 가운데 프레임 하나를 원래 길이만큼 반복한다. 섞기 조건은 같은 프레임들을 사전에 고정한 순열로 바꾼다. 두 조건 모두 원래 입력 길이를 유지한다.

| 마지막 1,680회 조건 | 초기값 42 완전 일치 | 초기값 42 CER | 초기값 43 완전 일치 | 초기값 43 CER |
|---|---:|---:|---:|---:|
| 정상 영상 | 12/12 | 0.00% | 12/12 | 0.00% |
| 정지 영상 | 8/12 | 28.03% | 8/12 | 22.73% |
| 프레임 순서 섞기 | 8/12 | 8.33% | 9/12 | 18.18% |

정상 영상이 더 좋은 결과를 냈으므로 시간 변화에 대한 민감성은 일부 관찰된다. 그러나 정지 영상에서도 상당수를 그대로 맞힌다. 학습 구절의 외양, 화자·녹화 특성, 입력 길이 또는 특정 입 모양 등으로 정답을 기억했을 가능성이 남는다. 이번 대조만으로 어느 단서가 원인인지 분리할 수는 없다. 순서를 섞어도 원래 프레임 집합이 남고 정지 영상에도 한 프레임의 정보가 남으므로, 이 대조를 ‘영상 정보를 모두 제거한 시험’으로 해석하지 않는다.

8명 중 구절이 하나뿐인 4명(C004/C293/C297/C312)은 두 모델의 정지·섞기 조건에서도 모두 4/4 정확했다. 구절이 두 개씩 있는 나머지 4명의 8클립은 정지 조건에서 각각 4/8이었다. 입력 길이도 9종이고 그중 6개 클립은 길이만으로 다른 클립과 구별된다. 이는 자료 구성의 혼재 요인을 보여 주는 사후 통계이며, 화자 외양이나 길이가 실제 원인임을 입증한 실험은 아니다.

## 검증과 실제 사용량

- 실행기 14개·로더 16개·평가기 18개, 총 48개 테스트를 통과했다. 같은 로더 테스트를 임시 정책과 정식 정책에서 반복한 것은 별도 32개로 세지 않았다.
- 사전검사 8업데이트에서 최대 배치와 학습률 전환, 저장 후 재개를 확인했다. 두 초기값 모두 연속 실행과 재개 실행의 모델·Adam·난수 상태가 완전히 일치했다.
- 본학습 3,360업데이트, 사전검사 포함 **실제 최적화 3,368회**다. 본 체크포인트 8개와 사전 체크포인트 8개를 저장했다.
- 고정 평가 144건·확률 144파일·5,772프레임의 입력 변환, 토큰 출력, 문자 복원, 점수를 독립 검산했다. 실패 0건이며 독립 Float64 CTC 최대 절대 차이는 2.85×10⁻¹⁴ 미만이다.
- 추가 저장 출력 분석의 정답·greedy 288개 CTC 계산, 56개 손실 구간, blank·토큰 통계와 화자별 대조 분포도 독립 검산했다. 이 분석은 새 모델 실행을 하지 않았다.
- 본학습 실제 프레임 269,360, 패딩 포함 315,946, 정답 토큰 152,320개다. 학습·평가·사전검사 전체 신경망 호출은 3,512회다.
- 본 실행 구간은 약 262.30초였다. 코드 준비·테스트·사전검사·최종 감사 시간은 포함하지 않는다. 본학습 PyTorch 최대 할당 약 383.56MiB, 예약 520MiB였으며 전체 GPU 사용량을 뜻하지 않는다.
- 기존 동결 자료 1,498항목과 보호 범위 10항목의 보존을 확인했다. 원본 영상·음성 읽기, 교사 호출, 다운로드, 서비스 가중치 변경은 0회다.

`provisional=true`, `training_ready=false`, 정밀 시각 경계 미승인 상태를 유지한다. 기존 30캐시의 경계 주의 표시는 2개이며, 이번 12학습 구절에 해당하는 것은 1개다. OOV 부모 제외 상태도 유지했다. 이 실험은 기존 검수 자료의 제한된 기술적 사용이며 추가 사람 승인을 만들어 낸 것이 아니다.

## 다음에는 무엇을 할 것인가

**학습량 연장이나 전체 문장 확대보다, 고정된 최종 모델이 학습하지 않은 구절을 읽는지 먼저 확인한다.** 이번 결과로 소집합 학습 가능성은 확인했지만, 엄격한 두 시점 기준과 움직임 의존성에는 한계가 남았기 때문이다.

다음 별도 5d에서는 두 최종 모델을 고정하고, 이미 준비된 내부 개발 구절 3개의 정상·정지·섞기 결과를 비교하는 소규모 진단을 제안한다. 2모델×3구절×3조건=18평가이며, 새 학습은 하지 않는 방향이다. 대상은 “많이 해서 잠이 부족해”, “너무 많이 막혀”, “너무 불편한 것 같아”다. 이번 5c에서는 이 세 구절을 모델에 넣지 않았다.

이 개발3은 과거 실험과 설계에서 이미 사용한 기존 화자의 탐색용 자료다. 후속 평가가 좋아도 독립 최종 성능이나 새 화자·웹캠 성능으로 주장하지 않는다. 최종 일반화 검증에는 별도의 검수된 녹화·전사 분리 자료가 필요하다. 현재 보유 자료부터 조사하며, 미검수 후보를 자동으로 학습·평가에 넣지 않는다.

5d는 다음 작업을 위한 제안으로 **아직 실행하지 않았다.** 별도 평가 범위·정책·체크포인트 해시를 고정한 뒤 진행해야 한다. 이전에 제안한 ‘양쪽 전체 문장 노출을 같게 하는 비교’와 원래 6단계 문장 확대는 보류한다. **바로 다음 소규모 진단에는 추가 다운로드나 코랩이 필요하지 않다.**
