## 2. 촬영 자리 만들기 (10분, 하루 한 번)

1. **장소**: 조용하고 사람이 지나가지 않는 방. 같은 장소를 계속 쓴다.
2. **조명**: 천장 조명을 켜고, 얼굴 **앞쪽**이 밝게. 창문을 등지고 앉지 않는다(역광이면 입이 어둡게 나온다). 해가 드는 시간대가 바뀌면 커튼을 친다.
3. **배경**: 흰 벽이나 단순한 배경. 뒤에 다른 사람·움직이는 화면이 없게.
4. **카메라**: 화면 위쪽 가운데, **눈높이**. 노트북이면 책을 받쳐 높인다.
5. **거리**: 얼굴과 카메라 사이 **50~70cm**(팔을 뻗었을 때 손끝 정도).
6. **화면 속 얼굴 크기**: 얼굴(이마~턱)이 화면 세로의 **1/3 이상**, 가운데. 얼굴이 작으면 입술을 못 찾는다.
7. **의자**: 등받이 있고 바퀴 없는 의자. 촬영 중 의자를 움직이지 않는다.
8. 자리를 다 맞추면 **사진을 한 장** 찍어 두고, 다음 날 같은 자리를 그대로 만든다.

**찍히는 사람 준비**: 마스크·모자 벗기, 머리카락이 입을 가리지 않게 묶기, 안경은 평소대로(반사가 심하면 조명 각도 조정), 껌·사탕 금지.

## 3. 프로그램 켜기 (5분)

1. 터미널을 열고 프로젝트 폴더(`lipnet_project`) 안의 `frontend` 폴더에서 촬영 화면을 켠다. 서버·모델은 켜지 않아도 된다.
   ```bash
   cd frontend
   npm.cmd run dev
   ```
   PowerShell에서는 `npm` 대신 `npm.cmd`를 쓴다(그냥 `npm`은 실행 정책 때문에 막힐 수 있다). 이 터미널은 촬영이 끝날 때까지 켜 둔다.
2. 브라우저(Chrome/Edge)로 `http://localhost:5173/#capture` 를 연다.
3. 화면 맨 위에서 **이 순서대로**:
   1. **가명 ID** 입력 (P01 등)
   2. **촬영 묶음** 선택: P01·P02는 "파일럿·조정용", P03 이후는 "최종 평가용"
   3. **저장 폴더 선택** → 묶음에 맞는 폴더(파일럿은 `pilot`, 최종 평가는 `eval`) → 브라우저가 폴더를 보고 바꿔도 되는지 물으면 모두 허용
   4. **카메라 열기** → 브라우저가 카메라 권한을 물으면 허용
4. **녹화 전 확인 (매번)**:
   - [ ] 버튼에 `저장 폴더: pilot`(P01·P02) 또는 `저장 폴더: eval`(P03~)이 보인다.
   - [ ] 문장 상자 위 작은 회색 줄이 `파일럿·조정용 · 1 / 100`(P01·P02) 또는 `최종 평가용 · 1 / 140`(P03~)으로 시작한다.
   - [ ] 새 사람인데 주황색 **"가명 ID '…'로 저장된 클립이 … 있습니다"** 문구나 **이어 찍기** 버튼이 보이면, 이미 쓴 가명 ID다. 녹화하지 말고 가명 ID를 고친다(그대로 찍으면 다른 사람 영상을 덮어쓴다).
   - [ ] 영상에 얼굴이 2장의 크기·위치로 보인다.

화면에 나올 수 있는 안내:

| 안내 | 뜻 |
|---|---|
| "이 폴더에 '…' 클립 기록 N개가 있어 촬영 묶음을 고정했습니다" | 그 폴더에 이미 누가 찍었다는 뜻. 정상이다. |
| "이 폴더에는 '파일럿·조정용' 클립이 있는데 지금 고른 촬영 묶음은 '최종 평가용'입니다" | 폴더나 묶음을 잘못 골랐다. 묶음을 다시 보고 맞는 폴더를 고른다. |
| "저장 폴더를 먼저 고르세요" | 폴더를 고르기 전에는 녹화되지 않는다. |
| 주황색 "가명 ID '…'로 저장된 클립이 … 있습니다" + 이어 찍기 | 같은 사람이 이어 찍을 때만 정상(9장). 새 사람이면 가명 ID가 잘못됐다. |

## 4. 동의서와 기록지 (5분)

1. 동의서 내용을 읽어 주고 서명을 받는다. 시연 영상 사용 여부(선택 항목)를 꼭 체크한다. 외부 참가자에게는 문의·철회 연락처와 본인 가명 ID를 알려 준다(동의서 사본을 줘도 된다).
2. 기록지 위쪽 칸(가명 ID, 날짜, 촬영 묶음, PC·웹캠, 조명·배경, 안경 여부)을 채운다. 실제 fps는 첫 클립을 찍은 뒤 적는다(5-1).
3. 동의서는 실명이 있으므로 **영상 폴더와 다른 곳**에 보관한다.
4. 찍히는 사람은 5-3의 대사표를 소리 내어 한 번, 소리 없이 한 번 미리 읽어 본다(5분).

## 5. 촬영 순서와 대사

### 5-1. 녹화 한 번 하는 법 (모든 클립 공통)

스페이스바는 **찍히는 사람이 직접** 누른다(초록색 "녹화 시작" 버튼을 마우스로 눌러도 된다).

1. 화면에 나온 문장을 **눈으로 읽고 외운다.**
2. **카메라 렌즈 쪽을 보고** 입을 편하게 다문다.
3. **스페이스바** → 영상 왼쪽 위에 빨간 **● REC**가 뜬 것을 보고 → 속으로 "하나"(1초) → 말한다 → 끝나고 속으로 "하나"(1초) → **스페이스바**.
   - ● REC가 안 뜨면 말하지 말고 촬영 담당이 화면을 확인한다.
4. 저장되면 자동으로 다음 순번으로 넘어간다.

- 잘못 읽었거나, 웃었거나, 기침했거나, 고개를 돌렸으면 → **"이전 (다시 찍기)"** → 같은 문장을 다시 녹화한다(같은 이름으로 덮어쓴다). 다시 찍은 뒤에는 이미 저장된 다음 클립을 건너뛰고 아직 안 찍은 순번으로 간다.
- 회색 줄 끝에 `이미 저장됨(녹화하면 덮어씀)`이 보이면 그 칸은 이미 찍은 칸이다. 다시 찍을 때만 녹화한다.
- 한 클립은 8초가 지나면 자동으로 멈춘다. 문장은 2~4초라 여유가 있다.
- 저장 뒤 주황색 **⚠ 경고**(녹화가 1초보다 짧음, 실제 프레임이 적음, 영상이 멈춤)가 뜨면 "이전 (다시 찍기)"로 다시 찍는다. 프레임이 적다는 경고면 조명을 밝게 하고 카메라를 쓰는 다른 프로그램을 끈다.

**첫 클립을 찍은 뒤 한 번만**:
- 화면 아래 **"마지막 저장: … 추정 NNfps · 최대 간격 NNms"** 줄을 본다. 추정 fps가 25 이상이면 좋다. 이 값을 기록지의 fps 칸에 적는다. (카메라 옆에 보이는 `@ 30fps`는 카메라에 요청한 값이라 실제와 다를 수 있다.)
- 새 탭(Ctrl+T)을 열고, 저장 폴더의 `.webm` 파일을 **그 새 탭에** 끌어다 놓아 재생해 본다. 촬영 화면 탭에 놓으면 촬영 화면이 사라진다. 얼굴이 가운데에 충분히 크게, 밝게 나오는지 확인하고, 아니면 자리를 고친 뒤 촬영 탭으로 돌아가 "이전 (다시 찍기)"로 다시 찍는다.

| N10 | 주말마다 아이들이랑 놀이터에서 놀아 |

A는 학습 자료(AI Hub)에 있던 문장, N은 새로 만든 문장이다. 두 묶음의 결과를 나눠 비교하므로 **글자 하나도 바꾸지 말고** 화면 그대로 읽는다.

**소리 내어 말하기**: 평소 대화하듯 보통 속도로, 또박또박. 일부러 크게 입을 벌리거나 천천히 끊어 읽지 않는다.

**소리 없이 말하기**: 목소리도 속삭임도 없이 **입 모양만**. 속도와 입 모양은 소리 낼 때와 똑같이. 과장하지 않는다. 숨을 크게 내쉬며 "후" 소리를 내지 않는다.

### 5-4. 자유 문장 10개 (순번 81~90 / 121~130)

| ID | 주제 |
|---|---|
| F01 | 아무 말이나 |
| F02 | 오늘 한 일 |
| F03 | 좋아하는 음식 |
| F04 | 내일 계획 |
| F05 | 지금 기분 |
| F06 | 자주 가는 곳 |
| F07 | 주말에 하고 싶은 일 |
| F08 | 날씨 |
| F09 | 친구에게 할 말 |
| F10 | 부탁하고 싶은 일 |

1. 주제를 보고 **말할 문장을 먼저 정한다.**
2. 촬영 담당에게 그 문장을 먼저 말해 주고, 촬영 담당은 **기록지에 그대로 적는다.** 소리가 저장되지 않기 때문에 이 기록이 정답이 된다.
3. 5-1 방법으로 **소리 내어** 녹화한다. 적은 문장과 다르게 말했으면 기록지를 실제로 말한 대로 고치거나 다시 찍는다.

규칙 (화면 안내와 같다):
- 한 문장, 3초 안쪽, 한국어만.
- 영어 단어, 숫자, 사람 이름, 사는 곳·학교·회사 이름, 가게 이름은 넣지 않는다.
- 위 대사표 문장을 그대로 쓰지 않는다.

## 7. 한 사람 촬영이 끝나면 (5분)

1. **폴더 점검**: 새 터미널을 열고 프로젝트 폴더(`lipnet_project`)에서 아래를 실행한다. 인식은 하지 않는다. 최종 평가용은 `pilot`을 `eval`로 바꾼다.
   ```bash
   py -3.11 scripts/pilot_evaluate.py check --clips D:/silent_talk_webcam/pilot
   ```
   - `"ok": true` 이고 `"problems": []` 이면 정상.
   - `"sessions"`가 pilot 폴더는 `["pilot"]`, eval 폴더는 `["eval"]`인지 본다. pilot 폴더의 `"participants"`에는 P01·P02만 있어야 한다.
   - 방금 찍은 사람의 `"clips"`가 `"expected"`(100 또는 140)와 같은지 본다. 모자라면 아래 2번처럼 바로 다시 찍는다.
   - `자유 문장 받아쓰기(spoken) 없음` 경고는 8장을 하기 전까지 정상이다.
2. **빠진 클립 다시 찍기**: 촬영 화면에서 같은 가명 ID·같은 폴더를 고르면 **이어 찍기** 버튼이 빠진 첫 순번으로 옮겨 준다.
3. **기록지 확인**: 자유 문장 10개가 모두 적혔는지, 특이사항이 있는지.
4. **백업**: 저장 폴더를 외장 디스크에 그대로 복사한다.
5. **다음 사람**: 촬영이 끝난 화면의 **"다음 사람 촬영"** 버튼을 누르고 새 가명 ID를 입력한 뒤 3장 4번(녹화 전 확인)부터 다시 한다. 날짜가 바뀌었거나 브라우저를 껐으면 3장 처음부터 한다.

| 중간에 새로고침·창 닫힘 | 같은 가명 ID 입력 → **같은 촬영 묶음 선택** → 같은 폴더 선택 → 카메라 열기 → **이어 찍기** 버튼 → 3장 4번 확인. |
