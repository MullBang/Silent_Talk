# 웹캠 촬영 가이드 (촬영하는 사람용)

이 가이드를 위에서부터 순서대로 따라 하면 된다. 프로그램 설치나 인터넷은 필요 없다. 혼자서 30~50분 걸린다.

## 0. 내 정보 (팀장에게 받아서 적기)

| 항목 | 적기 |
|---|---|
| 내 가명 ID | P__ |
| 촬영 묶음 | □ 파일럿·조정용 (100클립, 약 30~40분)  □ 최종 평가용 (140클립, 약 40~50분) |
| 보내는 마감 | ____월 ____일 |
| 보내는 방법 | □ USB로 직접  □ 팀장에게만 공유된 클라우드 폴더 |

- 가명 ID와 촬영 묶음은 팀장이 정해 준 그대로 쓴다. 다른 사람과 같은 가명 ID를 쓰면 안 된다.
- 파일 이름, 메시지, 메모 어디에도 실명 대신 가명 ID만 쓴다.

## 1. 준비물

- [ ] 웹캠이 있는 PC (노트북 내장 카메라도 된다)
- [ ] Chrome 또는 Edge 브라우저
- [ ] 받은 압축 파일을 **압축 풀기**한 폴더 (`웹캠촬영.html`, `촬영가이드.html`, `동의서.html`이 들어 있다. 압축 파일 안에서 바로 열지 않는다)
- [ ] 영상을 저장할 **빈 폴더** 하나. 이름에 가명 ID를 넣는다. 예: `silent_talk_P02`
  - 바탕화면·문서 폴더가 OneDrive나 iCloud로 동기화되면 영상이 자동으로 인터넷에 올라간다. 그럴 때는 동기화되지 않는 곳에 만든다(Windows: `C:\silent_talk_P02`, Mac: 홈 폴더 안 `silent_talk_P02`).
- [ ] 조용하고 아무도 들어오지 않는 방에서 30~50분
- [ ] 물 (녹화 중에는 마시지 않는다)

## 2. 동의서

1. `동의서.html`을 열어 끝까지 읽는다.
2. 인쇄해서 서명한다. 프린터가 없으면 종이에 "웹캠 촬영 동의서 내용을 읽고 동의함, 날짜, 가명 ID, 서명"을 손으로 쓰고 서명해도 된다. 시연 영상 사용(선택 항목)에 동의하는지도 적는다.
3. 서명한 종이를 사진 찍어 팀장에게 보낸다. **영상 압축 파일과 따로** 보낸다(동의서에는 실명이 있다).

## 3. 촬영 자리 만들기 (10분)

1. **조명**: 방 불을 켜고 얼굴 **앞쪽**이 밝게. 창문을 등지고 앉지 않는다(역광이면 입이 어둡게 나온다). 밤이면 책상 조명을 얼굴 앞에 둔다.
2. **배경**: 흰 벽이나 단순한 배경. 뒤에 다른 사람이나 켜진 TV가 없게.
3. **카메라**: 화면 위쪽 가운데, **눈높이**. 노트북이면 책을 받쳐 높인다.
4. **거리**: 얼굴과 카메라 사이 **50~70cm** (팔을 뻗었을 때 손끝 정도).
5. **화면 속 얼굴 크기**: 얼굴(이마~턱)이 화면 세로의 **1/3 이상**, 가운데. 얼굴이 작으면 입술을 못 찾는다.
6. **의자**: 바퀴 없는 의자가 좋다. 촬영 중 의자와 카메라를 움직이지 않는다.
7. **나**: 마스크·모자 벗기, 머리카락이 입을 가리지 않게 묶기, 안경은 평소대로, 껌·사탕 금지.

## 4. 프로그램 열기 (5분)

1. 압축을 푼 폴더에서 `웹캠촬영.html`을 **Chrome 또는 Edge**로 연다.
   - Windows: 파일을 오른쪽 클릭 → 연결 프로그램 → Chrome(또는 Edge).
   - Mac: 기본으로 Safari가 열린다. 파일을 Control+클릭(오른쪽 클릭) → 다음으로 열기 → Google Chrome.
2. 화면 맨 위에서 **이 순서대로**:
   1. **가명 ID** 입력 (예: P02)
   2. **촬영 묶음** 선택: 0장에서 받은 묶음
   3. **저장 폴더 선택** → 1장에서 만든 빈 폴더 → 브라우저가 폴더를 보고 바꿔도 되는지 물으면 모두 허용
   4. **카메라 열기** → 카메라 권한을 물으면 허용
3. **녹화 전 확인**:
   - [ ] 버튼에 `저장 폴더: (내 폴더 이름)`이 보인다.
   - [ ] 문장 상자 위 작은 회색 줄이 `파일럿·조정용 · 1 / 100` 또는 `최종 평가용 · 1 / 140`으로 시작한다(내 묶음과 같아야 한다).
   - [ ] 영상에 내 얼굴이 3장의 크기·위치로 보인다.

화면에 나올 수 있는 안내:

| 안내 | 할 일 |
|---|---|
| 노란 상자 "폴더에 바로 저장할 수 없어, 찍은 클립을 이 화면에 모아 둡니다" | 찍을 수는 있다. 대신 **20클립마다, 그리고 다 찍은 뒤 "찍은 클립 N개 내려받기 (zip)"** 를 누른다. 내려받기 전에 창을 닫으면 그 사이 클립이 사라진다. 보낼 때는 가장 마지막에 받은 zip 하나만 보낸다(11장). 가능하면 Chrome이나 Edge로 다시 열어 폴더 저장으로 찍는 것이 좋다. |
| "저장 폴더를 먼저 고르세요" / "가명 ID를 먼저 입력하세요" | 그 칸을 채우면 녹화할 수 있다. |
| 주황색 "폴더를 고를 때 가명 ID '…'로 저장된 클립이 이미 … 있었습니다" + 이어 찍기 | 내가 찍다가 끊긴 뒤 같은 폴더를 다시 고른 경우에만 정상이다(12장). 처음 찍는데 보이면 폴더나 가명 ID를 잘못 골랐다. |

## 5. 녹화 한 번 하는 법 (모든 클립 공통)

1. 화면에 나온 문장을 **눈으로 읽고 외운다.**
2. **카메라 렌즈 쪽을 보고** 입을 편하게 다문다.
3. **스페이스바** → 영상 왼쪽 위에 빨간 **● REC**가 뜬 것을 보고 → 속으로 "하나"(1초) → 말한다 → 끝나고 속으로 "하나"(1초) → **스페이스바**.
   - ● REC가 안 뜨면 말하지 않는다. 회색 줄과 주황색 안내를 먼저 본다.
   - 스페이스바 대신 초록색 "녹화 시작" 버튼을 눌러도 된다.
4. 저장되면 자동으로 다음 순번으로 넘어간다.

**혼자 확인할 것 (매 클립)**: 문장을 화면과 똑같이 말했나? 얼굴이 화면 안에 있었나? 입을 가리거나 웃거나 기침하지 않았나? 하나라도 아니면 **"이전 (다시 찍기)"** 를 누르고 같은 문장을 다시 녹화한다(같은 이름으로 덮어쓴다). 다시 찍은 뒤에는 원래 하던 순번으로 돌아간다.

- 회색 줄 끝에 `이미 저장됨(녹화하면 덮어씀)`이 보이면 이미 찍은 칸이다. 다시 찍을 때만 녹화한다.
- 한 클립은 8초가 지나면 자동으로 멈춘다. 문장은 2~4초라 여유가 있다.
- 저장 뒤 주황색 **⚠ 경고**가 뜨면:
  - "녹화가 1초보다 짧습니다", "영상이 멈췄습니다" → "이전 (다시 찍기)"로 다시 찍는다.
  - "실제 프레임이 적습니다" → 조명을 더 밝게 하고, 카메라를 쓰는 다른 프로그램(줌, 카톡 영상통화 등)을 끄고, 노트북은 전원을 연결한 뒤 한 번 다시 찍는다. 그래도 같으면 카메라의 한계이니 그대로 계속 찍고 메모에 적는다.
- 지나간 클립을 다시 찍고 싶으면 화면 아래 **"순번으로 가기"** 에 순번을 넣고 "이동"을 누른다. 다 찍은 뒤 마지막 클립은 "마지막 클립 다시 찍기"로 다시 찍는다.

**첫 클립을 찍은 뒤 한 번만**: 새 탭(Ctrl+T, Mac은 Command+T)을 열고, 저장 폴더의 첫 영상 파일(`.webm`)을 **그 새 탭에** 끌어다 놓아 재생해 본다. 촬영 화면 탭에는 놓지 않는다(촬영 화면이 사라진다). 얼굴이 가운데에 충분히 크게, 밝게 나오는지 보고, 아니면 자리를 고친 뒤 촬영 탭으로 돌아가 "이전 (다시 찍기)"로 다시 찍는다. 화면에 모아 두는 경우(노란 상자)에는 첫 클립을 찍고 "내려받기 (zip)"로 받은 zip을 풀어 그 안의 영상을 같은 방법으로 재생한다.

촬영 전에 이 표를 소리 내어 한 번, 소리 없이 한 번 읽어 본다(5분). 촬영할 때는 **글자 하나도 바꾸지 말고** 화면 그대로 읽는다.

- **소리 내어 말하기**: 평소 대화하듯 보통 속도로, 또박또박. 일부러 크게 입을 벌리거나 천천히 끊어 읽지 않는다.
- **소리 없이 말하기**: 목소리도 속삭임도 없이 **입 모양만**. 속도와 입 모양은 소리 낼 때와 똑같이. 과장하지 않는다.

## 8. 자유 문장 10개

| ID | 주제 |
|---|---|
| F01 | 아무 말이나 |
| F02 | 오늘 한 일 |
| F03 | 좋아하는 음식 |
| F04 | 내일 계획 |
| F05 | 지금 기분 |
| F06 | 자주 가는 곳 |
| F07 | 주말에 하고 싶은 일 |
| F08 | 날씨 |
| F09 | 친구에게 할 말 |
| F10 | 부탁하고 싶은 일 |

1. 주제를 보고 **말할 문장을 정한다.**
2. 화면의 입력 칸에 그 문장을 **그대로 적고 Enter**를 누른다. 소리가 저장되지 않으므로 이 글이 정답이 된다.
3. 5장 방법으로 **소리 내어**, 적은 그대로 말하며 녹화한다. 다르게 말했으면 "이전 (다시 찍기)"로 돌아가 다시 적고 다시 찍는다.

규칙:
- 한 문장, 3초 안쪽, 한국어만. 한글과 띄어쓰기만 쓴다(문장부호 없이). 숫자·영어·문장부호를 적으면 입력 칸 아래에 안내가 뜨고 녹화가 안 된다.
- 사람 이름, 사는 곳·학교·회사 이름, 가게 이름은 넣지 않는다(프로그램이 막지 못하니 스스로 지킨다).
- 7장 대사표 문장을 그대로 쓰지 않는다.

## 9. 말하지 않기 10개

| ID | 화면 지시 |
|---|---|
| X01~X03 | 입을 다문 채 가만히 카메라를 보세요 |
| X04~X05 | 입을 살짝 벌린 채 가만히 있으세요 |
| X06 | 소리 없이 살짝 미소 지으세요 |
| X07 | 소리 없이 활짝 웃는 표정을 지으세요 |
| X08 | 고개를 천천히 두세 번 끄덕이세요 |
| X09 | 침을 한 번 삼키고 입술을 한 번 적시세요 |
| X10 | 입을 다문 채 코로 숨을 크게 한 번 쉬세요 |

스페이스바 → 지시대로 **약 3초** → 스페이스바. 말이나 소리는 내지 않는다. "말하지 않을 때 글자가 잘못 나오는지"를 재는 영상이라 이것도 중요하다.

## 10. 쉬는 때

- 20클립(한 회차)마다 1분 쉰다. 의자와 카메라는 움직이지 않는다.
- 소리 내어 → 소리 없이로 바뀌기 전에 3분 쉰다.
- 물은 쉬는 시간에만 마신다.

## 11. 다 찍었으면

1. 화면에 "촬영이 끝났습니다"가 나온다.
2. **폴더에 저장한 경우**: 저장 폴더의 파일 수를 본다. 파일럿·조정용은 **200개**(영상 100 + 기록 100), 최종 평가용은 **280개**(영상 140 + 기록 140)여야 한다. 모자라면 같은 가명 ID·같은 폴더로 프로그램을 다시 열고 **이어 찍기**로 빠진 클립을 찍는다.
3. 이상했던 클립이 있으면 `가명ID_메모.txt`(예: `P02_메모.txt`)를 만들어 적는다. 예: `silent A05 2회차 - 중간에 웃음`. 폴더에 저장했으면 그 폴더 안에 둔다.
4. **폴더에 저장한 경우**: 저장 폴더를 오른쪽 클릭 → **압축**(Windows: 보내기 → 압축(ZIP) 폴더 / Mac: Control+클릭 → 압축)한다. 압축 파일 이름은 가명 ID로 시작하게 한다. 예: `P02_웹캠촬영.zip`
   **화면에 모아 둔 경우(노란 상자)**: "내려받기 (zip)"로 받은 `P02_웹캠촬영.zip` 중 **가장 마지막에 받은 것 하나**를 보낸다(다운로드 폴더에 있다). 메모가 있으면 같이 보낸다. 다운로드 폴더 전체를 압축하지 않는다.
5. 0장의 방법으로 팀장에게 보낸다. **단톡방, 공개 링크, 공유 드라이브의 공개 폴더에는 올리지 않는다.**
6. 팀장이 잘 받았다고 하면 내 PC의 저장 폴더와 압축 파일(다운로드 폴더의 zip 포함)을 지운다.

| 상황 | 할 일 |
|---|---|
| `웹캠촬영.html`이 다른 프로그램으로 열린다 | Windows: 오른쪽 클릭 → 연결 프로그램 → Chrome 또는 Edge. Mac: Control+클릭 → 다음으로 열기 → Google Chrome. |

| 실제 프레임이 적다는 ⚠ 경고 | 조명을 밝게, 카메라 쓰는 프로그램 끄기, 노트북은 전원 연결. 그 뒤 "이전"으로 한 번 다시 찍는다. 그래도 같으면 그대로 계속 찍고 메모에 적는다. |

| "…클립이 있는데 지금 고른 촬영 묶음은 …입니다" 오류 | 촬영 묶음이나 폴더를 잘못 골랐다. 0장의 내 묶음과 1장의 내 폴더인지 확인한다. |
| 잘못 읽었는데 이미 다음으로 넘어갔다 | "이전 (다시 찍기)"를 눌러 돌아가 다시 찍는다. |
| 촬영 묶음 선택이 회색으로 잠겼다 | 정상이다. 한 클립이라도 저장했거나, '건너뛰기'를 눌렀거나, 폴더에 이미 클립이 있으면 잠긴다. 묶음을 잘못 골랐으면 팀장에게 알리고 새 빈 폴더로 처음부터 찍는다. |
| 그 밖에 막히면 | 화면을 캡처해서 팀장에게 보낸다. |
