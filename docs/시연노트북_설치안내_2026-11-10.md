# 시연 노트북 설치 안내 (병실 무음 도우미)

이 문서는 개발 PC가 아닌 **시연용 Windows 노트북**에 Silent Talk 병실 무음 도우미를 설치하고, 켜고, 점검하는 방법을 순서대로 적었습니다. 처음 해 보는 사람도 그대로 따라 하면 됩니다.

- 설치할 때 **한 번만** 인터넷이 필요합니다. 설치가 끝나면 인터넷 없이 시연할 수 있습니다.
- 노트북에는 **Python 3.11 하나만** 설치합니다. Node.js와 Git은 필요 없습니다.
- 시연용 연구 시제품입니다. 실제 환자에게 검증하지 않았고, 호출벨을 대신하지 않습니다.

---

## 1. 준비물

| 항목 | 조건 |
|---|---|
| 노트북 | Windows 10 또는 11 (64비트) |
| 디스크 | 설치하는 동안 C: 드라이브에 **GPU판 16GB, CPU판 10GB 이상** 비어 있어야 합니다. 설치한 프로그램(GPU판 약 6.6GB, CPU판 약 2.8GB)과 내려받는 파일·임시 파일이 함께 들어갑니다. GPU판에 공간이 모자라고 CPU판에는 충분하면 자동으로 CPU판으로 설치합니다. 설치 후 남는 "내려받은 파일 보관분"(GPU판 약 3.4GB)은 지울 수 있습니다(10절 표). |
| 웹캠 | 720p 이상 (노트북 내장 카메라도 됩니다) |
| 그래픽카드 | NVIDIA가 있으면 빠르지만 **없어도 됩니다** (병실 모드는 CPU로도 동작). GTX 10xx처럼 오래된 그래픽카드(세대 7.0 미만)는 CPU판으로 설치합니다. |
| 그래픽 모드 (게이밍 노트북) | 제조사 앱(Armoury Crate, Lenovo Vantage, MSI Center 등)에서 그래픽 모드가 **Eco·절전·내장 그래픽 전용**이면 NVIDIA 그래픽카드가 숨겨져 CPU판이 설치됩니다. 설치와 시연 전에 **표준(Standard)·Optimus(하이브리드)** 또는 **외장 그래픽(dGPU)** 으로 바꿔 둡니다. |
| Visual C++ 재배포 패키지 | Microsoft Visual C++ 2015-2022 (x64). 게임·그래픽 드라이버를 깐 노트북에는 대부분 이미 있습니다. 없으면 `설치.bat`이 1단계에서 알려 줍니다 (2-3절). |
| 인터넷 | 설치할 때 한 번 (GPU판은 약 3.4GB, CPU판은 약 0.7GB를 내려받습니다) |
| 브라우저 | Chrome 권장 (없으면 Edge를 씁니다) |
| 개발 담당에게 받을 파일 | `SilentTalk_시연패키지_날짜.zip` (약 380MB) |

## 2. 노트북에 프로그램 설치 (처음 한 번)

### 2-1. Python 3.11 설치

1. 아래 주소에서 설치 파일을 받습니다.
   https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
2. 받은 파일을 실행합니다.
3. 첫 화면 **아래쪽의 "Add python.exe to PATH"를 꼭 체크**하고 **Install Now**를 누릅니다.
4. "Setup was successful"이 나오면 닫습니다.

> 3.12나 3.13이 이미 있어도 괜찮습니다. 3.11을 **추가로** 설치하면 됩니다. Microsoft Store의 파이썬이 아니라 위 python.org 설치 파일을 써 주세요.

### 2-2. Chrome 설치 (없을 때만)

https://www.google.com/chrome/ 에서 설치합니다. 없으면 Edge로 자동으로 엽니다.

### 2-3. Visual C++ 재배포 패키지 설치 (없을 때만)

인식 프로그램(torch)과 입술 추출 프로그램(mediapipe)이 이 패키지의 파일(`MSVCP140.dll`)을 씁니다. 파이썬에는 들어 있지 않습니다.

1. 설정 → 앱 → 설치된 앱에서 **"Microsoft Visual C++ 2015-2022 Redistributable (x64)"** 가 있는지 봅니다. 있으면 이 절은 건너뜁니다.
2. 없으면 아래 주소에서 받아 실행합니다. 동의에 체크하고 **설치**를 누릅니다.
   https://aka.ms/vs/17/release/vc_redist.x64.exe
3. 끝나면 노트북을 다시 시작합니다.

> 잘 모르겠으면 그냥 `설치.bat`을 실행해도 됩니다. 1단계에서 확인하고, 없으면 이 주소를 알려 주고 멈춥니다.

## 3. 묶음 파일 풀기

1. 받은 `SilentTalk_시연패키지_날짜.zip`을 오른쪽 클릭 → **속성**을 누릅니다. 아래쪽에 "보안: 이 파일은 다른 컴퓨터에서 가져왔으므로..."가 보이면 **차단 해제**에 체크하고 **확인**을 누릅니다.
   - 이걸 하지 않으면 `.bat` 파일을 실행할 때마다 "열기 - 보안 경고" 창이 뜹니다.
2. zip을 오른쪽 클릭 → **압축 풀기...** 를 누릅니다.
3. 풀 위치를 **`C:\`** 로 바꿉니다. (기본으로 나오는 다운로드 폴더 경로를 지우고 `C:\` 만 남깁니다.)
4. 다 풀리면 **`C:\SilentTalk`** 폴더가 생깁니다. 안에 `설치.bat`, `시연_실행.bat`, `시연_점검.bat`, `시연_중지.bat`이 있어야 합니다.

> **폴더 경로에 한글이 있으면 안 됩니다.** 입술 추출 프로그램(mediapipe)이 한글 경로에서 모델 파일을 열지 못할 수 있습니다. 그래서 설치 스크립트는 한글 경로에서 멈추고 옮기라고 알려 줍니다. `C:\SilentTalk`를 권장합니다.
>
> zip 안의 파일 일부만 복사하지 말고 **폴더 전체**를 그대로 두세요. 숨김 폴더(`.git`)도 필요합니다.

## 4. 설치하기 — `설치.bat`

1. 인터넷(Wi-Fi)을 연결합니다.
2. `C:\SilentTalk\설치.bat`을 두 번 클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
   - "열기 - 보안 경고" 창이 뜨면 **실행**을 누릅니다. (3절 1번의 차단 해제를 하면 뜨지 않습니다.)
3. 검은 창에서 11단계가 차례로 진행됩니다. **GPU판은 20~40분, CPU판은 5~15분** 걸립니다(인터넷 속도에 따라 다름). 진행 막대가 멈춘 것처럼 보여도 기다려 주세요.

하는 일:

| 단계 | 내용 |
|---|---|
| 1 | 파이썬 3.11(64비트), Visual C++ 재배포 패키지 확인 |
| 2 | 묶음 확인: 폴더 경로, 모델 가중치 지문(SHA-256), 공식 모델 코드 버전, 병실 명령 20개, 화면 파일 |
| 3 | 시연 프로그램이 꺼져 있는지 확인 |
| 4 | 그래픽카드 확인 → GPU판 또는 CPU판 선택 |
| 5 | 디스크 여유(GPU판 16GB, CPU판 10GB), 인터넷 확인 |
| 6~8 | 가상환경 3개 설치: 서버(`.venv-server`), 입술 추출(`.venv-olkavs-roi`), 인식(`.venv-olkavs`) |
| 9 | git 확인 (없으면 대신 쓸 작은 프로그램을 만듭니다. Git을 설치할 필요 없음) |
| 10 | 실제로 입술 추출·인식 프로그램을 띄워 준비되는지 확인 |
| 11 | 요약 |

**성공하면** 마지막에 이렇게 나옵니다.

```
================================================================
 설치 완료
================================================================
  파이썬          : 3.11.9
  그래픽카드      : NVIDIA GeForce RTX ... (또는 없음)
  인식용 torch    : 2.10.0+cu128 (GPU판)   ← 그래픽카드가 없으면 2.10.0+cpu (CPU판)
  인식 장치       : cuda:0 ...             ← CPU판이면 cpu
  입술 추출       : mediapipe 0.10.21
  VC++ 런타임     : MSVCP140 14.xx...
  가중치 지문     : 일치 (f41d742380af11b7...)
  git             : 대체 명령(git 설치 불필요)
  ...
  다음 단계: 시연_실행.bat 을 두 번 클릭하세요.
```

- **중간에 실패하거나 창을 닫아도 괜찮습니다.** 원인을 고친 뒤 `설치.bat`을 다시 실행하면 끝난 부분은 건너뛰고 이어서 합니다.
- NVIDIA 그래픽카드가 있는데 GPU 계산이 안 되면(오래된 드라이버 등) 자동으로 CPU판으로 바꿔 설치합니다. 드라이버가 CUDA 12.0~12.7까지만 지원하면 GPU판을 먼저 시도해 보고, 안 되면 CPU판으로 바꿉니다.
- 설치 기록은 `C:\SilentTalk\deploy\runtime\logs\` 에 남습니다.

옵션(보통은 필요 없음): 명령 프롬프트에서 `C:\SilentTalk\설치.bat --device cpu` 처럼 실행합니다.

| 옵션 | 뜻 |
|---|---|
| `--device cpu` | 그래픽카드가 있어도 CPU판으로 설치 (나중에 옵션 없이 다시 실행하면 그래픽카드에 맞춰 GPU판으로 바뀝니다) |
| `--device cuda` | GPU판을 강제 (드라이버를 최신으로 바꾼 뒤 다시 시도할 때) |

## 5. 시연 켜기 — `시연_실행.bat`

1. `C:\SilentTalk\시연_실행.bat`을 두 번 클릭합니다.
2. **"Silent Talk 서버"** 창과 **"Silent Talk 화면"** 창이 새로 뜹니다. **이 두 창은 시연이 끝날 때까지 닫지 마세요.** (최소화는 괜찮습니다.)
3. 모델을 불러오는 동안 기다립니다. GPU는 약 30초, CPU는 1~3분입니다.
4. 준비되면 브라우저 창이 **두 개** 열립니다.
   - 환자 화면: `http://localhost:5173/#ward`
   - 간호사 화면: `http://localhost:5173/#nurse`
5. **간호사 화면에서 [소리 켜기]를 한 번 누릅니다.** (안 누르면 알림음이 나지 않습니다.)
6. 환자 화면에서 처음 녹화할 때 카메라 권한을 물으면 **허용**을 누릅니다.
7. 프로젝터를 쓰면 **Windows 키 + P → 확장**을 고르고, 간호사 창을 프로젝터 화면으로 끌어 옮깁니다.
8. 프로젝터를 HDMI로 연결하면 소리가 프로젝터로 넘어가는 일이 많습니다. **작업 표시줄 스피커 아이콘 → 출력 장치를 노트북 스피커**로 바꿉니다.

예상 출력:

```
  서버와 모델을 켭니다... (Silent Talk 서버 창, PID ...)
  화면을 켭니다... (Silent Talk 화면 창, PID ...)
모델을 불러오는 중입니다. 잠시 기다려 주세요 (GPU 약 30초, CPU는 1~3분)...
  ... 서버 켜는 중 (0초)
  ... 서버 응답함, 입술 추출 켜는 중, 인식 켜는 중 (6초)
  [통과] 준비 완료: 인식 장치 GPU (NVIDIA GeForce ...), 병실 명령 20개     ← CPU판이면 "인식 장치 CPU"
  [통과] 병실 기준값: 동결 값 (1·2등 차이 ..., 1등 점수 ..., 긴급 가능성 하한 ..., 등록 거리 ...)
  [통과] Chrome으로 환자 창과 간호사 창을 열었습니다.
```

- "[주의] 이 묶음에는 동결한 병실 기준값이 없어 코드 기본값으로 판정합니다"가 나오면 개발 담당에게 알립니다. 기준값을 정하기 전에 만든 묶음입니다(11절).
- "[주의] 서버 병실 기준값이 묶음의 동결 값과 다릅니다"가 나오면 `시연_중지.bat` 후 `시연_실행.bat`으로 다시 켭니다.

- 이미 켜져 있을 때 다시 실행하면 **새로 켜지 않고** 브라우저 창만 다시 엽니다.
- 켜는 도중에 `시연_실행.bat`을 한 번 더 누르면, 나중 창은 아무것도 켜지 않고 "다른 창에서 이미 시연을 켜는 중입니다"만 보이고 끝납니다. 먼저 연 창을 기다리면 됩니다.
- 카메라 없이 연습: `http://localhost:5173/#ward?practice=1` (등록 화면에 다녀와도 연습 모드가 유지됩니다)
- 서버·화면 창을 클릭해 글자를 선택하면 예전에는 서버가 멈추는 일이 있었습니다. 이 묶음은 그 기능(빠른 편집)을 꺼 두었지만, 두 창은 되도록 건드리지 마세요.

**주의:** 두 브라우저 창은 반드시 **같은 주소(`localhost:5173`)와 같은 브라우저**로 열려야 서로 통합니다. `127.0.0.1:5173`으로 열거나, 하나는 Chrome·하나는 Edge로 열거나, 시크릿 창으로 열면 간호사 화면에 요청이 오지 않습니다.

### 5-1. 시연 전: 환자 역할 조원의 "내 입 모양 등록"

등록은 **이 노트북 서버에** 저장됩니다. 개발 PC에서 한 등록은 노트북에 없으므로, 환자 역할을 할 사람을 노트북에서 한 번 등록합니다(약 5분). 등록하지 않아도 시연은 되지만, 그때는 글자 규칙만으로 고릅니다.

1. 환자 화면 오른쪽 위 **[설정]** → "내 입 모양 등록" → **[새로 등록하기]**. (녹화·확인·선택 중이거나 확인하지 않은 긴급 알림이 있으면 버튼이 눌리지 않습니다. 간호사 화면에서 확인한 뒤 엽니다.)
2. 등록 이름에 실명 대신 별명을 적고(영문·숫자·`_`·`-`, 예: `actor1`) **[등록 시작]**.
3. 명령 20개가 하나씩 나옵니다. 화면 가운데의 **큰 문장(인식용 문장)** 을 **소리 내어 평소처럼 한 번** 말합니다. 스페이스바나 [녹화 시작]을 누르면 5초 동안 찍고 저절로 멈춥니다. 작은 글씨는 간호사실에 보이는 문장입니다.
4. "다른 문장으로 알아들었어요"가 나오면 **[다시 찍기]** 로 또박또박 다시 찍습니다. 저장에 실패하면 이유가 나오고 같은 명령을 다시 찍습니다.
5. 20개를 다 찍으면 끝 화면이 나옵니다. **"확인 필요 N개"** 상자가 있으면 그 명령의 [다시 찍기]로 다시 찍습니다. 그대로 쓰려면 [그래도 이 등록 쓰기]를 눌러야 병실 화면이 이 등록을 씁니다.
6. **[병실 화면으로]** → 환자 화면 카메라 아래의 상태 줄이 **"내 입 모양 등록: actor1 (20/20)"** 인지 확인합니다. "다 찍지 않아 아직 쓰지 않아요"면 설정 → [등록 화면 열기]로 빠진 명령을 찍습니다.

- 이미 있는 등록을 열어 보기만 해서는 병실 화면의 등록이 바뀌지 않습니다. 쓸 등록은 설정의 "병실 화면이 비교할 등록"에서 고르거나 끝 화면의 [병실 화면에서 이 등록 쓰기]로 정합니다.
- 상태 줄이 **"명령 목록이나 인식 모델이 바뀌어 지금은 쓰지 않아요"**(다시 등록 필요)이면 새 묶음(8절)으로 명령 목록이나 가중치가 바뀐 것입니다. 등록 화면의 [이 등록 지우고 처음부터]로 지우고 다시 등록합니다. 이 상태에서는 녹화가 되지 않습니다.

### 5-2. 등록 자료는 개인 자료입니다 — 시연 뒤 지우기

- 저장 위치: `C:\SilentTalk\backend\data\ward_profiles\<등록 이름>\` (명령별 입 모양 특징 파일과 기록 파일). 영상은 저장하지 않습니다.
- 새 묶음을 같은 폴더에 덮어써도(8절) 등록은 **지워지지 않고 남습니다.**
- **시연이 끝나면 지웁니다:** 환자 화면 [설정] → "내 입 모양 등록"에서 그 등록을 고르고 **[이 등록 지우기]** → 확인. 여러 개면 하나씩 지웁니다. 서버를 끈 뒤 `C:\SilentTalk\backend\data\ward_profiles` 폴더를 통째로 지워도 됩니다.
- 노트북을 돌려주거나 다른 사람에게 넘기기 전에 이 폴더가 비었는지 확인합니다.

### 5-3. (선택) 내 목록 — 직접 만든 문장으로 병실 화면 쓰기

기본 명령 20개 대신 직접 쓴 문장 4~20개로 병실 화면을 쓸 수 있습니다. 쓰지 않으면 지금까지와 똑같이 기본 목록으로 동작합니다. 자세한 방법과 문장 규칙은 `docs/병실_내목록_사용법_2026-11-11.md`에 있습니다.

> **먼저 확인:** 이 기능은 내 목록 기능을 **커밋한 뒤** `py -3.11 deploy\build_bundle.py --freeze docs\병실명령_동결_2026-11-10.json`로 **다시 만든 묶음**에만 있습니다. 묶음은 커밋된 코드(HEAD)로 만들기 때문에, 그 전에 만든 묶음에는 [내 목록 관리]가 없습니다. 노트북에 다시 설치한 뒤 환자 화면 [설정]에 **[내 목록 관리]** 가 보이는지, `시연_점검.bat` 2구역에 "'내 목록' 저장 폴더에 쓸 수 있음"이 나오는지 먼저 확인하세요.

1. **환자 화면 창에서** [설정] → **[내 목록 관리]** 를 누릅니다(같은 창에서 목록 화면으로 넘어갑니다). 간호사 창이나 새 탭에서 따로 열지 않는 것을 권합니다.
2. [+ 새 목록 만들기]로 만들거나 **[예시 목록 불러오기]** ("재활 병동" 10문장)로 채운 뒤, 목록 ID(영문·숫자, 예: `rehab1`)를 확인하고 **[저장]**. 빨간 글씨(오류)가 있으면 저장되지 않습니다.
3. **[이 목록으로 병실 화면 쓰기]** → 병실 화면 위에 "내 목록 ‘<이름>’ 사용 중 · 성능을 측정하지 않은 목록" 띠가 보이는지 확인합니다.
4. **[이 목록으로 입 모양 등록하기]** 로 환자 역할 조원을 등록합니다. 등록은 **목록마다 따로**입니다. 기본 목록 등록은 그대로 남고, 내 목록 등록은 `C:\SilentTalk\backend\data\ward_profiles\lists.d\<목록 ID>\<등록 이름>\`에 저장됩니다.
5. 기본 목록으로 돌아가려면 [설정] → "명령 목록" → **기본 목록**.

- 내 목록은 **성능을 측정하지 않은 목록**입니다. 시연에서 정확도를 말할 때는 기본 목록의 측정값만 씁니다.
- 연습 모드(`?practice=1`)는 늘 기본 목록을 씁니다. 가상 병실 효과(불·커튼·TV)는 기본 목록에만 있습니다.
- 내 목록을 불러오지 못하면 입 읽기 녹화가 꺼지고 기본 목록으로 저절로 바뀌지 않습니다. 이때도 스위치 3번 긴급 호출은 됩니다. [설정]에서 목록을 다시 고릅니다.
- **시연 뒤 지우기:** #lists에서 목록을 고르고 [이 목록 지우기]를 하면 그 목록의 등록도 함께 지워집니다. 서버를 끈 뒤 `C:\SilentTalk\backend\data\ward_profiles`(등록)와 `C:\SilentTalk\backend\data\ward_lists`(목록 문장) 폴더를 통째로 지워도 됩니다. 새 묶음을 덮어써도 두 폴더는 남으니, 노트북을 돌려주기 전에 비었는지 확인합니다.

## 6. 점검하기 — `시연_점검.bat`

`시연_실행.bat`으로 켜 둔 상태에서 `C:\SilentTalk\시연_점검.bat`을 두 번 클릭합니다. 약 1~3분 걸립니다.

| 구역 | 확인 내용 |
|---|---|
| 1. 컴퓨터 | CPU, 메모리, 전원 어댑터 연결, 배터리 절약 모드, 그래픽카드, Windows 한국어 음성(음성 읽기용) |
| 2. 서버 상태 | 두 워커 준비, 인식 장치(GPU/CPU), 병실 명령 20개, 병실 기준값이 묶음의 동결 값과 같은지, "내 입 모양 등록" 저장 폴더에 쓸 수 있는지, "내 목록" 저장 폴더에 쓸 수 있는지(내 목록 기능이 없는 옛 묶음이면 주의), 가중치 지문, 공식 코드 버전, 화면과의 연결 허용(CORS) |
| 3. 화면 서버 | 화면 파일이 올바르게 오는지 |
| 4. 카메라 | 0번 카메라에서 영상 한 장을 읽을 수 있는지 (저장하지 않음. 환자 창이 카메라를 쓰는 중이면 실패로 나올 수 있으며 정상입니다) |
| 5. 처리 시간 | 들어 있는 예시 영상 3개를 병실 묶음으로 7번, 문장 묶음으로 3번 보내 결과가 오는지와 걸린 시간(중앙값·90%·최대) |
| 6. 오프라인 점검 | 화면 파일에 인터넷이 필요한 주소가 남았는지 |
| 7. 직접 확인할 것 | 아래 9절 목록 |

예상 출력(마지막 줄):

```
 점검 결과: 실패 0개, 주의 0개, 통과 13개      ← 통과 개수는 노트북마다 조금 다를 수 있습니다
 결과 파일: C:\SilentTalk\deploy\runtime\check_reports\check_날짜_시각.json
```

- **결과 파일을 개발 담당에게 보내 주세요.** (처리 시간·장치 정보가 들어 있습니다. 영상은 들어 있지 않습니다.)
- 예시 영상은 조정 참가자(P01)의 문장 녹화라 병실 명령이 아닙니다. 그래서 "고르지 않음"이 나와도 정상입니다. 이 점검은 결과가 돌아오는지와 **시간**만 봅니다(정확도 측정이 아님).
- 병실 묶음의 참고 목표는 "녹화 끝 → 화면 표시 3초 이내"입니다. 예시 영상은 8초 녹화라 실제 병실 녹화(5초)보다 조금 오래 걸릴 수 있습니다.
- 카메라를 건드리지 않으려면 명령 프롬프트에서 `시연_점검.bat --no-camera`로 실행합니다.

`시연_중지.bat`은 이 폴더에서 켠 서버·화면만 끄고, 다른 프로그램은 건드리지 않습니다.

## 8. 새 묶음(업데이트 zip)을 받았을 때

개발 담당이 기준값을 고치거나 화면을 바꾸면 새 zip을 다시 보냅니다. 이미 설치한 환경(`.venv-...` 폴더, GPU판 약 6GB)은 그대로 두고 **같은 폴더에 덮어씁니다.**

1. **인터넷을 연결합니다.** 패키지 목록이 바뀐 묶음이면 바뀐 것만 새로 받아야 합니다.
2. `시연_중지.bat`을 실행하고 브라우저 창도 닫습니다. (켜져 있으면 파일이 잠겨 덮어쓰기가 실패합니다.)
3. 새 zip을 오른쪽 클릭 → **속성 → 차단 해제** → 확인.
4. 새 zip을 오른쪽 클릭 → **압축 풀기...** → 위치를 처음과 같은 **`C:\`** 로 둡니다. "같은 이름의 파일이 있습니다" 창이 뜨면 **대상 폴더의 파일 바꾸기**를 누릅니다.
   - `C:\SilentTalk` 폴더를 지우거나 다른 폴더에 풀지 마세요. 그러면 처음부터 다시 설치(GPU판 20~40분)해야 합니다.
5. `설치.bat`을 실행합니다. 패키지 목록이 그대로면 설치된 환경을 그대로 쓰고 모델 기동만 다시 확인해서 **약 20초**면 끝납니다. 목록이 바뀌었으면 바뀐 환경만 다시 맞춥니다.
   - 2단계 "묶음 정보" 줄의 빌드 날짜가 새 zip 날짜인지 확인합니다.
6. `시연_실행.bat` → `시연_점검.bat`으로 실패 0개인지 확인합니다.
7. 환자 화면 상태 줄의 등록을 확인합니다. 새 묶음에서 명령 목록이나 가중치가 바뀌었으면 등록이 **"다시 등록 필요"** 로 바뀝니다. 그때는 5-1절대로 지우고 다시 등록합니다. (덮어쓰기로 등록 자료는 지워지지 않습니다. 5-2절)

## 9. 오프라인 리허설 (11/13 전에 꼭 한 번)

1. 노트북을 **전원 어댑터에 연결**합니다.
2. 설정 → 시스템 → 전원: **화면 끄기·절전 "안 함"**. Windows 업데이트 → **업데이트 일시 중지**. 알림 → **방해 금지 켜기**.
3. (인터넷이 될 때) `시연_점검.bat` 1구역에 "한국어 음성을 찾지 못했습니다"가 나왔으면 **설정 → 시간 및 언어 → 음성 → 음성 추가 → 한국어**를 설치합니다. 음성은 인터넷이 있어야 받을 수 있으니 인터넷을 끄기 전에 합니다.
4. **Wi-Fi만 끕니다** (작업 표시줄 → Wi-Fi 끄기). 유선 랜이 꽂혀 있으면 뽑습니다.
   - 블루투스 스위치·키보드를 쓰면 **비행기 모드를 켜지 마세요.** 비행기 모드는 블루투스도 끕니다. 켰다면 블루투스를 다시 켭니다.
5. 노트북을 다시 시작합니다. (다시 시작한 뒤에도 Wi-Fi가 꺼져 있는지 봅니다.)
6. `시연_실행.bat` → 두 창이 열리는지 확인합니다.
7. 간호사 화면에서 **[소리 켜기]**.
8. 프로젝터를 연결하고 **Windows 키 + P → 확장**, 간호사 창을 프로젝터로 옮깁니다. 그다음 **작업 표시줄 스피커 아이콘 → 출력 장치를 노트북 스피커**로 맞춥니다.
9. `시연_점검.bat` → 실패 0개인지 확인합니다.
10. 환자 역할 조원을 등록했는지(5-1절) 확인합니다: 환자 화면 상태 줄이 **"내 입 모양 등록: <이름> (20/20)"** 이어야 합니다.
    그다음 시연 대본대로 처음부터 끝까지 해 봅니다: 스위치(키보드·발판)로 녹화 시작 → 입 모양 → 환자 화면 결과 → 간호사 화면 도착(알림음이 노트북에서 들리는지) → [확인]. 긴급 명령, 목록에 없는 말, 3초 안에 3번 누르기(긴급 호출)도 해 봅니다.
11. 인터넷이 꺼진 상태에서 **음성 읽기(한국어)** 가 나오는지 확인합니다.
12. 환자 화면의 "호출벨과 함께 쓰는 보조 수단" 안내가 보이는지 확인합니다.
13. 리허설에서 만든 카드가 간호사 화면에 남아 있으면 모두 [확인]한 뒤 **[확인한 카드 지우기]**를 누릅니다. (카드 기록은 이 노트북 브라우저에만 저장됩니다.)
14. 리허설용으로만 만든 등록이면 [설정] → [이 등록 지우기]로 지웁니다. 본 시연에 쓸 등록은 남겨 두고, **본 시연이 끝난 뒤** 지웁니다(5-2절).
15. 끝나면 `시연_중지.bat`.

**최후 대안:** 노트북에서 시연이 안 되면 개발 PC로 녹화한 백업 영상으로 시연합니다. 백업 영상과 점검 결과 파일을 USB에 챙겨 두세요.

## 10. 문제 해결

| 증상 | 해결 방법 |
|---|---|
| `설치.bat`이 "파이썬 3.11을 찾지 못했습니다" | 2-1절대로 python.org의 3.11.9 (64-bit)을 설치하고 "Add python.exe to PATH"를 체크했는지 확인합니다. 설치 후 창을 새로 열어 다시 실행합니다. |
| "Visual C++ 재배포 패키지가 없습니다", 또는 "DLL load failed", "WinError 126", "WinError 1114", "DLL 오류" | 2-3절대로 https://aka.ms/vs/17/release/vc_redist.x64.exe 를 설치합니다(이미 있다고 나오면 **복구**). 노트북을 다시 시작한 뒤 `설치.bat`을 다시 실행합니다. 끝난 부분은 건너뜁니다. |
| "인터넷에 연결되지 않았습니다" | Wi-Fi를 연결합니다. 학교·회사 망이 막으면 휴대폰 테더링으로 해 봅니다. 설치가 끝난 뒤에는 인터넷이 필요 없습니다. |
| "남은 공간이 ...GB입니다", 또는 설치 중 "디스크 공간 부족" | C: 드라이브를 GPU판 16GB, CPU판 10GB 이상 비우고 다시 실행합니다. 명령 프롬프트에서 `py -3.11 -m pip cache purge` 를 실행하면 예전에 내려받은 파일 보관분(GPU판 약 3.4GB)이 지워집니다. 설치가 끝난 뒤에도 같은 명령으로 지워도 됩니다(시연에는 필요 없음). |
| "묶음 폴더 경로에 한글이 있습니다" | 폴더를 `C:\SilentTalk`로 옮기고 다시 실행합니다. 이미 만든 `.venv-...` 폴더는 지우고 다시 설치합니다(가상환경은 옮기면 동작하지 않습니다). |
| "가중치 파일이 원본과 다릅니다" | zip이 복사 중 손상됐습니다. zip을 다시 받아 처음부터 풀어 주세요. |
| 그래픽카드가 있는데 CPU판이 설치됨 | 4단계 설명 줄에 이유가 나옵니다. ① GTX 10xx처럼 세대 7.0 미만 그래픽카드: GPU판 torch가 지원하지 않습니다. ## 11. 개발 담당용: 묶음 만들기와 확인 기록

### 묶음 만들기 (개발 PC)

```
py -3.11 deploy\build_bundle.py --freeze docs\병실명령_동결_2026-11-10.json --sample-clips
```

- 출력: `바탕화면\SilentTalk_시연패키지_YYYYMMDD\SilentTalk\` 폴더와 그 옆의 `SilentTalk_시연패키지_YYYYMMDD.zip`.
  zip 안의 최상위 폴더 이름은 영문 `SilentTalk`입니다(노트북 경로에 한글이 들어가지 않게).
- 코드(backend·frontend·scripts·`experiments/olkavs_official` 추적 파일)는 **커밋된 HEAD**에서 꺼냅니다. 커밋하지 않은 변경은 들어가지 않고 경고로 알립니다. 코드 폴더(backend·frontend/src·scripts)에 **커밋하지 않은 새 파일이 있으면 만들지 않습니다**(커밋한 코드가 그 파일을 쓰면 노트북에서 서버가 켜지지 않기 때문입니다. 필요 없는 파일이면 `--allow-dirty`). **기준값 동결 커밋 뒤에 다시 만들어야 합니다.** 노트북에는 8절 방법(같은 폴더에 덮어쓰기 → `설치.bat`)으로 넣습니다.
- **`--freeze <커밋한 동결 파일>`**: 동결 파일의 병실 기준값 4개(1·2등 차이, 1등 점수, 긴급 가능성 하한, 등록 거리 D)를 묶음의 `deploy\ward_thresholds.json`에 넣습니다. 노트북 서버는 다른 `LIPNET_*` 값을 모두 지우고 이 4개만 넣어 켜지며, `시연_실행.bat`·`시연_점검.bat`이 `/health`의 기준값과 같은지 확인합니다(다르면 점검 실패). 동결 파일은 묶을 커밋에 들어 있고, 커밋 뒤 고치지 않았고, `status`가 `frozen`이고 형식 검사(`full_list.env` 포함)를 통과해야 합니다. `--freeze` 없이 만들면 코드 기본값으로 판정하며, 묶을 때·켤 때·점검 때 주의로 알립니다.
- 화면(`frontend/dist`)은 꺼낸 코드로 새로 빌드합니다(작업 폴더의 `frontend/dist`는 건드리지 않음).
- 공식 모델 코드 `upstream/`(.git 포함, 약 41MB)과 가중치 `multiview_lip.pt`(약 304MB)는 작업 폴더에서 복사하고 SHA-256을 확인합니다. zip도 다시 열어 CRC와 가중치 SHA-256을 확인합니다.
- `deploy/`의 스크립트·고정 목록과 이 안내 문서는 작업 폴더에서 복사합니다.
- `--sample-clips`: 점검용 예시 영상으로 조정 참가자 **P01**의 무음 문장 녹화 3개만 넣습니다. **P02(최종 평가 대상) 폴더·파일은 거부합니다.** `check.py --samples <폴더>`도 폴더 경로나 파일 이름에 P02가 있으면 아무것도 보내지 않고 실패로 알립니다.
- 다시 만들 때는 `--force` (이전 묶음 폴더만 지웁니다).

### 알려진 한계

- 처리 시간 목표(3초)는 시연 노트북에서 직접 재야 합니다. 위 숫자는 개발 PC 값입니다.
- 실시간 웹캠(compact) 화면은 묶음에 compact 가중치가 없어 노트북에서 쓰지 않습니다(병실·간호사·녹화 화면만 대상).
- 파일 업로드 화면의 python-magic 검사는 노트북에서 파일 시그니처 검사로 대신합니다(기존 폴백 규칙).
- Visual C++ 재배포 패키지가 없는 깨끗한 Windows는 이 PC에서 재현하지 못했습니다(이 PC에는 있음). 없을 때의 안내는 단위 시험으로만 확인했습니다.
- CUDA 12.0~12.7 드라이버에서 GPU판이 실제로 도는지는 그런 노트북에서 확인하지 못했습니다. 안 되면 자동으로 CPU판으로 바뀝니다.
