# 공식 모델 전환 9단계 — 처음 보는 사람(P02) 최종 평가 결과 (2026-11-09)

> 설정은 [8단계 고정 기록](공식모델_전환_08_설정고정_2026-11-09.md)(커밋 e9ec4b7) 그대로이고, 평가 방법도 그 문서 3절에 미리 적은 대로다. P02 결과를 보고 바꾼 설정은 없다. 독립 검산에서 모든 수치가 재현됐다.

## 1. 요약

**처음 보는 사람 P02에게도 지정 문장 모드의 안전 규칙이 지켜졌다.**
- 화면에 표시한 문장 중 틀린 것은 0개였다.
- 목록에 없는 말이나 말하지 않은 영상을 문장으로 표시한 경우도 0개였다.

이는 **1명**에 대한 결과다. 같은 날 같은 문장을 여러 번 읽은 영상이고, 목록 밖·무발화 영상 수가 적어 0이라는 결과의 불확실성이 크다.

## 3. 보조 결과

### 3.1 조정용 100클립과 합계

P02의 두 묶음은 같은 날 찍었으므로, 합쳐서 처음 보는 사람 1명으로 본다.

| 지표 | 조정용 100 | **합계 240** |
|---|---|---|
| 1등 정답 소리 / 무음 | 40/40 / 38/40 | 100/100 / 98/100 |
| 표시 / 표시 중 오답 | 74/80 / 0/74 | **187/200 / 0/187 (상한 1.6%)** |
| 목록 밖 잘못 표시 | 0/10 | **0/20 (상한 13.9%)** |
| 말하지 않기: 문장 표시 / 받아쓰기 글자 표시 | 0/10 / 1/10 | 0/20 / 3/20 |

조정용에서 1등이 틀린 2개(무음 N03, N04)는 1·2등 차이가 0.22와 0.09라서 표시되지 않았다.

### 3.2 받아쓰기 (아무 말이나 받아쓰기)

|---|---|---|---|

| 소리, A01~A10 | 15.5% / 15.6% | 66.7% / 71.9% | 35.7% / 37.1% |
| 소리, N01~N10 | 47.9% / 52.1% | 87.0% / 93.4% | 72.2% / 79.3% |
| 무음, A01~A10 | 45.4% / 51.0% | 69.6% / 74.2% | 55.4% / 60.6% |
| 무음, N01~N10 | 61.0% / 66.4% | 82.5% / 86.3% | 74.9% / 82.0% |
| 완전 일치 (목록 문장) | 13/120 (11개가 소리 A) | 0/80 | 1/80 |

- P02는 세 사람 중 받아쓰기 오류율이 가장 낮았다.
- A 문장(모델이 학습했을 가능성이 있는 문구)과 새 N 문장의 차이가 크다. 소리 내어 말한 경우 15.5%와 47.9%다.
- 새 문장을 소리 없이 말했을 때는 여전히 61%가 틀렸고, 완전 일치는 0/30이었다. 받아쓰기는 계속 보조 기능이다.

### 3.3 일괄 경로 (`pilot_evaluate.py run`, 앞뒤 자르기 없음)
- 입술 검출 240/240클립, 모든 프레임에서 성공했다.
- 지정 문장 1등은 서비스 경로와 200클립 모두 같았다. 길이만 보는 기준선은 7/120으로, 우연 수준(1/20)이었다.
- 하이브리드 문자 오류율(평가용)은 소리 A 18.1%, 소리 N 50.5%, 무음 A 47.0%, 무음 N 63.9%였다.

### 3.4 등록 방식 오프라인 분석 (미리 정한 규칙: 글자 규칙 통과 또는 자기 등록 거리 ≤ 0.27)

| 시험 | 등록 규칙 적용 표시 / 오답 | 글자 규칙만 |
|---|---|---|
| E1: 1회차 등록 → 같은 조건 2·3회차 (80) | **80/80 / 0** | 76/80 / 0 |
| E2: 소리 1회차 등록 → 무음 1~3회차 (60) | **60/60 / 0** | 53/60 / 0 |

- **소리 내어 한 번 등록하고 소리 없이 쓰는 방식**에서, 처음 보는 사람이 놓친 새 문장 6개를 모두 정답으로 살렸고 오답은 없었다.
- 글자 1등과 등록 1등이 다른 경우는 없었다.
- 걸러야 할 영상 중 등록 영상과 가장 가까운 것도 거리 0.321로, 기준(0.27)보다 0.051 멀었다.
- 등록과 시험은 같은 날 몇 분 간격으로 찍은 영상이다. 다른 날, 다른 조명에서의 결과는 아니다.
- 이것은 측정일 뿐이고, 서비스 기능이 아니다.

## 4. 녹화 조건 차이 (참고)
- P02는 Edge로 녹화했고(P01·P03은 Chrome), 녹화 시작 직후 약 0.27초 멈춤이 대부분의 클립에 있다. 발화 중간이 끊긴 것은 아니다.
- 입술 크기는 세 사람 중 가장 작았다(중앙값 100px, P01 109px, P03 171px). 그래도 검출 실패는 없었다.

## 5. 해석과 한계

1. **주장할 수 있는 것:** 고정 설정으로, 기준 조정에 쓰지 않은 사람 1명에게서 지정 20문장 중 표시한 187개가 모두 정답이었다. 목록 밖 말과 말하지 않은 영상을 문장으로 표시한 경우는 없었다.
2. **주장할 수 없는 것:**
   - 처음 보는 사람 일반의 성능. 1명뿐이다.
   - 잘못 표시가 정말 드물다는 것. 목록 밖·무발화가 각 20개뿐이라 상한이 13.9%다.
   - 새 문장 받아쓰기가 쓸 만하다는 것.
3. **P02가 특히 좋았던 이유는 확인하지 못했다.** 또박또박 말한 정도, 연습 효과(같은 날 같은 문장을 다섯 번 읽음), 조명 등이 섞여 있다.
4. **받아쓰기 신뢰도 기준(0.75)은 무발화를 막지 못했다.** P02는 신뢰도가 거의 다 0.75 이상이라(목록 문장 120/120), 모델까지 간 무발화 4개 중 3개에서 "언제나", "나" 같은 글자가 표시됐다. 지정 문장 표시는 0이었다. 병실 무음 도우미는 받아쓰기 글자를 쓰지 않고 지정 문장 결과만 쓰는 설계라 이 문제를 피한다.
