# 공식 모델 전환 8단계 — 설정 고정과 P02 평가 계획 (2026-11-09)

> 이 문서는 최종 평가 참가자 P02의 영상에 인식을 돌리기 **전에** 작성했다. 아래 설정과 평가 방법은 P02 결과를 보고 바꾸지 않는다. 바꾸면 사후 변경으로 따로 표시한다.

## 3. 미리 정한 평가 방법

### 3.1 주 결과: 최종 평가용 140클립, 실제 서비스 경로

고정 설정으로 다시 켠 서버에 클립을 하나씩 `POST /api/record`로 보내고 `GET /api/result`로 받는다.

| 지표 | 세는 방법 |
|---|---|
| 지정 문장 1등 정답 | 소리 내어 / 소리 없이, 각 60클립 |
| 화면 표시 / 표시 중 오답 | 기준(0.5, −3.40)을 넘은 수와 그중 틀린 수 |
| 목록 밖 자유 문장(F) 잘못 표시 | 10클립 |
| 말하지 않기(X) | [발화 없음] 수, 모델까지 간 수, 잘못 표시 수 |
| 나눠 보고 | A01~A10(모델 학습 문구일 가능성)과 N01~N10(새 문장) |

결과가 0이면 표본 수와 한쪽 95% 상한을 함께 적는다(예: 0/20 → 상한 약 14%). 처음 보는 사람은 1명뿐이라는 점도 함께 밝힌다.

### 3.2 보조 결과
1. **조정용 100클립(P02):** 같은 지표. P02의 두 묶음은 같은 날 찍었으므로, 두 결과를 합쳐 "처음 보는 사람 1명"으로 본다.
2. **받아쓰기:** 문자 오류율(띄어쓰기 포함·제외), 완전 일치, 신뢰도 0.75 이상 비율. [인식 불가]이면 후보 문장으로 센다.
3. **일괄 경로(`pilot_evaluate.py run`):** P01·P03 표와 같은 형식(입술 검출, 하이브리드·CTC 문자 오류율, 길이만 보는 기준선).
4. **처리 시간:** 서비스 경로의 클립당 시간.

### 3.3 등록 방식 오프라인 분석 (미리 정한 규칙)

서비스 기능이 아니라 측정만 한다. 특징과 비교 방법은 P01·P03 실험과 같다.
- **특징:** CTC 바로 앞 특징(T×256).
- **비교:** 코사인 거리로 DTW를 하고 경로 길이로 나눈다.

| 시험 | 등록 | 시험 |
|---|---|---|
| E1 같은 조건 | 평가용 1회차 (소리·무음 각각) | 같은 조건 2·3회차 (80클립) |
| E2 소리로 등록, 무음으로 사용 | 평가용 소리 1회차 | 무음 1~3회차 (60클립) |

- **판정 규칙(고정):** "글자 규칙(0.5, −3.40) 통과" 또는 "자기 등록 영상과의 거리 ≤ 0.27"이면 표시한다. 0.27은 P01·P03로 정한 값이다.
- **걸러 내기:** F 10개와 모델까지 간 X를 같은 규칙으로 센다.
- **함께 보고:** 글자 1등과 등록 1등이 다른 클립 수.

### 3.4 하지 않는 것
- P02 결과를 보고 기준값, 문장 목록, 발화 구간 설정을 바꾸지 않는다.
- P02 영상을 학습·조정에 쓰지 않는다.
- 결과에 1−오류율을 "정확도"로 적지 않는다.
